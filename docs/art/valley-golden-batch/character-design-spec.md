## 1. Style Anchors（旧正式美术）

旧 193 = 原作 171 张 120×120 手绘精灵（鸡 0:0–0:113、鸭 1:0–1:56）＋ 竹笼点心坊图集 6 只（0:114–0:119）＋ 四时食谱图集 16 只（鸡 0:120–0:127、鸭 1:57–1:64）。三批都在图鉴同一网格里并排显示，新 48 只必须能混在它们中间不被认出是“另一批”。

| 维度 | 锚点结论（来自逐张观察 [old-chickens/ducks contact sheet](../../../artifacts/art/valley-golden-batch/review) 与 [四时图集](../../../web/art/four-seasons-v12.png)） |
|---|---|
| 体型 | 头身一体的矮胖蛋形／团形；食物就是身体，不是“鸡戴食物”。四分之三视角，脸朝右。 |
| 眼睛 | 小圆豆眼（深棕近黑）＋一粒白高光；眼距近，位于身体上三分之一；淡桃色腮红允许但小而淡。 |
| 嘴 | 鸡：极小橙色尖喙朝右。鸭：明显更宽的扁橙嘴，眼位比鸡略低、贴近嘴根。 |
| 翅膀 | 两侧短小弧形翅，只用一条弧线或一片小翼表达，不画羽毛细节。 |
| 脚 | 两只极小的橙脚，完整露出；鸡三趾、鸭蹼足；脚间留空。 |
| 描边 | 连续的深暖棕描线（约 #553c2b），中等粗细，全身统一；不是黑线、不是贴纸白边。 |
| 上色 | 平涂柔和暖色，一块柔和的暗部（右下）＋一小块亮部；无渐变堆叠、无光泽 3D、无颗粒纹理。 |
| 食物融合 | 面部直接长在食物表面；食物结构（层、褶、切面）优先于装饰；配料是身体的一部分，不是道具。 |
| 复杂度 | 一个主形状＋一种主纹理＋最多两处小配料；120px 原稿在 48px 下仍能读出主形。 |
| 谷地配色 | 麦秆黄、荠菜绿、琥珀；干燥、哑光、家常，不用节庆红金。 |

参考图实际传给 ImageGen 的顺序（`--ref`）：`four-seasons-v12.png`（同类图集，含鸭）→ `style-anchor-originals.png`（16 张原作精灵 2.4× 拼板：0:0、0:3、0:4、0:16、0:109、0:111、0:113、0:91、1:0、1:8、1:13、1:18、1:22、1:53、1:56、1:26）→ `chick-v4-0.png`（标准鸡宝体型）。48 个 placeholder SVG 不作为参考。

## 3. 反“换皮”检查

- 12 个 silhouette 两两不同：扁圆 / 阶梯菱 / 圆锥 / 辫团 / 扇 / 水滴冠 / 横胶囊 / 削角长方 / 低堆探头 / 圆背砖 / 三角 / 凸背鸭。
- 只有 V-D2 与 V-D4 同属方块，靠高度、纹理、削角/圆背分开；生成后在 silhouette 预览中重点核对。
- 不为差异化加装饰：每只最多一种主纹理＋两处配料；没有帽子、丝带、道具。

## 4. Sheet 规格（两张）

- Valley Chickens Sheet：6 只鸡，3 列 × 2 行，顺序 V-C1…V-C6。
- Valley Ducks Sheet：6 只鸭，3 列 × 2 行，顺序 V-D1…V-D6。

- 统一：四分之三视角面朝右、同一光照（左上）、同一线宽、同一视觉体量（不同形状但占格面积接近）。
- 无文字、无 UI、无场景、无地面阴影、无棋盘格。
