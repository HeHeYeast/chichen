# 角色设计规范

版本1，2026-09-27。项目级规范，适用于新增地区、新角色、既有角色原创重绘；具体角色的Concept、色板、视觉梗和生产状态属于content数据，不写入本文。规范冻结创意自由与可读性，不冻结统一构图。

## Creative DNA

先写“材料或料理的性质 → 角色发生的事 → 一个可见的大形”。从以下机制选择适合内容的一种或组合，不按编号轮换套模板：

- 料理名转成动作或生活状态。
- 材料的软、脆、卷、折、延展性改变结构，但解剖关系须温和、易懂。
- 容器成为生活空间；道具必须改变姿态或表达因果，不能只是挂件。
- 烹饪前后差异成为状态、表情与轮廓。
- 一份食物的数量与连接关系成为角色关系，前提是统一槽位仍清楚。
- 食材色或性格色成为大色块；物种身份不依赖黄色。
- 一个来自性格、材料或动作后果的不对称点形成记忆。
- 角色与料理产生温和反差：先可爱、有趣，再怪趣；不以猎奇为目标。

## 必须同时成立

角色属于鸡宝/鸭宝世界；能读到料理或材料身份；至少一个强记忆点；旧图鉴低细节画法；自然稳定Idle；120px与48px能读到主体大形；统一Runtime槽位中不过宽过高。不能用大量小配料补救模糊主体，也不规定食物面积百分比。

鸡鸭可被料理包裹、使用料理、因料理而呈现状态，或让食物成为身体的一部分。保留可辨认的尖喙/宽鸭嘴、头胸腹与翼足关系。禁止难理解的扭结解剖、恐怖躯体、令人不适的穿透与畸变。材料特征不能违背content的料理与配方身份。

## Idle与视觉边界

允许站、坐、趴、蹲、缩、歪头、回头、抱持简单结构和有动作倾向的静止姿态。重心有落点，脚或腹部能稳定接触地面。禁止跑、跳、摔倒中间帧、大挥舞或必须靠动画解释的姿势。

默认可见宽高比0.65–1.50；特殊体型须内部记录理由、通过统一处理和所有槽位QA，硬边界0.55–1.65。外部结构不得独占大部分画布使鸟体小到不可读。不得以单角色CSS纠正设计问题。

## 内部Concept记录

每个Art Brief包含稳定ID、content关联、物种、主题身份、创意机制、强特征、Idle、体型、主/辅/点色、48px保留项、禁止细节、相似品对照、旧PNG参考、迭代记录。所有具体内容保存在生产数据中。

同一地区有轻微材料与性格倾向，但不统一体色。整批审查轮廓、配色、姿态、强特征、视觉梗、模板脸，以及与旧角色的近似。自动相似度只负责提示，不能代替视觉判断。相似项记录处置原因或重做。

## 内部审核与保密

不让玩家逐只审核。原生输出不自动通过；必须看120px、48px、浅深背景、源图与槽位。记录原始文件哈希、具体问题和结论。失败时Edit或Regenerate，旧审批随源图更换失效。

用户交付仅数量、地区进度、Runtime与QA状态和系统性问题。不展示角色、色板、Signature、视觉梗、sheet或包含未解锁内容的截图。内部图像和截图是生产内容，不是交付预览。只有改变整个方向的系统性问题才请求决策。
