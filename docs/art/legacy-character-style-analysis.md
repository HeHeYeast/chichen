## 6. 给 ImageGen 的约束语言（由数据得出）

1. 120×120 画布、角色宽高 60–90 px、脚贴底边；不要顶满画布。
2. 纯黑 2 px 描边，占体宽约 2.7%；允许轻微不匀，不要完美矢量线，不要棕色线。
3. 主色 ≤ 6 种；一个固体色＋一块暗部；高光 0–1 处；不要多层体积阴影。
4. 体内纹理密度接近素体（Laplacian 2–8）；料理细节以少量色块表达，不画材质。
5. 眼睛是黑豆眼，眼高约体高 7–9%；腮红默认没有；嘴小。
6. 蛋形/圆形为默认体型，站姿为默认姿态；不对称来自朝向、翅、尾、冠，不来自身体扭曲。
7. 边缘允许小凹凸，不是光滑蛋。

最重要的两个结论：**旧图描边是黑色**，此前所有 AI 版本（含现役 chick-v4）都用了暖棕；**长 prompt 会把线色、眼睛和纹理往“萌宠插画”推**，极短 prompt＋旧图参考时线色和密度自然回到旧图范围。
