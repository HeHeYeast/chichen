# 旧图鉴角色视觉语言与ImageGen约束

版本1，2026-09-27。本规范描述复用方法，不包含任何当前批次设计。创意方向见character-design-spec.md。

## 参考来源

旧193是项目身份集合，其中171张可追溯至原始鸡鸭PNG，另22张为后续扩展。复刻原作画法默认选171原始PNG；不把现代扩展、运行时重绘覆盖、placeholder、近期生成图、实验sheet或第三方API结果当作旧原作参考。通过稳定身份映射定位源PNG。未来旧193重绘也保留旧身份及源文件，新增可回退的替换版本。

每个请求使用多张同物种、相近复杂度或姿态的原PNG，参考只约束视觉语言，不复制旧角色身份。原图应实际查看，记录路径与哈希。

## 具体视觉语言

小型图鉴精灵：深棕至近黑的朴素轮廓，外线明确、内线少，轻微不匀而非刻意涂脏；常见少数平色块，少量局部阴影，不能推成柔光体积。简单豆眼、短弧闭眼或小白眼点；嘴型优先传达鸡鸭身份。腮红不统一添加，眼睛不统一放大。比例可矮、宽、瘦、歪，但结构直观。羽毛通常一两笔，食物以轮廓、折线、少量材料点表达。小尺寸仍应保留一件事，不以写实纹理证明料理。

颜色不固定为奶黄。有限色板由食物、烹饪状态、性格决定。粗糙是形体与笔触的自然不规则，不是噪点、纸纹滤镜或低质量压缩。

## 原生生成约束

使用当前环境原生image_gen.imagegen；不能转入第三方relay、项目自定义imagegen、mask测试或LoRA。每个候选独立请求。工具不提供的seed/quality参数不可虚构；记录实际工具与提示词，而非声称可锁定逐像素一致性。

提示词由通用画法约束＋content中的具体Concept＋参考角色角色说明组成。单个完整角色、透明背景、足够留白、稳定Idle、紧凑可见范围；无名字、编号、水印、UI标签、动作符号或地面投影。避免现代AI萌宠、巨大亮眼、统一腮红、精细羽毛、写实食品纹理、复杂渐变、3D、高级插画质感和完美矢量轮廓。

原生编辑须明确目标图、保留项、唯一问题和旧PNG参考；重生成是新候选，不能继承旧图的通过状态。生成调用可由当前代理处理请求清单；本地工具不伪装成原生生成器，也不隐式请求API密钥。

## 允许与禁止的处理

允许分离透明部件、删除确定为杂点的极小孤立像素、保留抗锯齿的透明裁边、等比缩放、留白、统一anchor，以及生成用途明确的portrait和silhouette衍生物。不得减色、提边重描、重画成SVG、拼旧角色主体或用程序风格归一化掩盖失败。

silhouette是Runtime未知态衍生资源，使用同一主体alpha与单一颜色并保留必要负空间；它不是用于修饰full的手段。单幅原生图不是人工分层源稿：保留原图、alpha、连通部件清单和裁切元数据，如实标记sourceLayersUnavailable，不伪造分层。
