# Visual Implementation Spec · 鸡宝厨房

> 阶段更新：收藏 Golden Sample 已通过。后续冻结范围以 [全局约束与营业 Golden Sample 规范](../business-golden-20260924/VISUAL-SPEC.md) 为准：冻结画风和工作流，不将收藏纸张、胶带、印章、格子、Tab、白边参数推广到所有系统。下文保留第一阶段设计记录，字体与具体尺寸以已通过的运行实现和后续冻结表为准。

2026-09-24。参考真值为本目录 mockups/01-business.png、02-journey.png、03-collection.png，均为887×1774。保持已确认方向，不再次探索画风。**本轮只实现收藏主题页 Golden Sample；生意、寻访仅制定规范。** 底栏新选中态先随 Golden Sample 验证，其余页面暂不扩散。

## A. 参考真值与优先级

成熟角色和场景的身份、画法 > 确认 Mockup 的材质与层次 > Mockup 的具体示例文字和数量。生成图不是角色原稿、字体文件或整屏背景。只允许两类明确差异：真实存档内容替换示意数据；按用户最新要求替换矩形底栏选中态。生成图中的角色微小变形不得反向覆盖已有角色。

验收基准390逻辑像素宽。参考图换算系数390/887=0.440；以下尺寸均为逻辑px。面向系统安全区内的游戏画面进行等宽比较，不把手机状态栏算进布局。宽度改变使用约束布局而不是整页缩放；320宽允许正文滚动，禁止为塞满首屏把名称压到12px以下。地图线与角色摆放属于动态UI，美术完成度不可由增加DOM卡片数衡量。

## B. 三图逐项视觉清单与责任划分

E=已有正式资产直接复用；A=新增独立位图美术；U=程序UI／文字／状态。A不包含现有概念SVG；技术上用SVG承载PNG裁切或透明轮廓滤镜，不等于用简单SVG画角色。

## C. 字体、间距、视觉密度

沿用项目 Chicken UI 字体（Noto Sans SC 子集，100–900字重），不把AI字形烘焙进图片。Mockup的手写感由粗字重、短文案与材质表达；不谎称已有字体与生成字形完全一样。

| 项目 | Golden Sample目标 | 允许边界 |
|---|---|---|
| 顶部“图鉴” | 26–28px / 900，行高1.2，配30px原鸡宝 | 不再占一整张大标题卡 |
| 主题标题 | 24px / 850–900，行高1.25 | 长主题22px或两行，不截掉核心名 |
| 角色名 | 16px / 800，行高1.35 | 与角色底部间隔8–10；长名两行 |
| 数量、页码 | 16px / 700，等宽数字 | 当前数叶绿，分母暖灰；名称不用等宽 |
| 印章字 | 16–18px / 800 | 和章框一起-8°旋转，不能反向单独转字 |
| 低频说明 | 14–16px，行高1.6 | 移入帮助／条件详情，首屏不放长段落 |
| 页边留白 | 12–16px；纸内左右24px | 两列角色间24–32px |
| 角色展示 | 两列三行；角色可见高度约100px | 自适应84–120px；320短屏保留最小轮廓并滚动 |
| 纸张与底栏 | 底栏外留6–10px；正文不被底栏遮挡 | 系统安全区单独计算 |
| 触区 | ≥44×44 | 小章、箭头和胶带不可互相抢触区；胶带不交互 |
| 密度 | 每页6个展示位、2条胶带、2个主章、1个纪念入口 | 收藏总候选更多时用“已收录”小入口查看，不塞满纸页 |

收藏六格是展示容量，不改现有主题候选池和代表条件。已收录但售空仍是已知彩图。未发现格使用统一中性纸片，不输出未知名字、图片链接或配方。所示数量不足六种时用未知纸片留出期待，但不把这六格改成六个固定任务。

## D. 可复用视觉组件合同

### CharacterSticker

输入：已公开角色ID、已知状态、展示尺寸、名称和动作。内部复用catalog/portrait frame，按可见alpha边界居中，保留原图比例；原棕线外膨胀4px暖白，再投下2px轻影。建议SVG滤镜仅做source-alpha dilation+shadow，或确定性alpha派生位图；不得生成替代角色。容器留8px滤镜安全边，不裁白边；胶带在独立顶层且pointer-events:none。普通、按压、键盘焦点、已选以层位和轻底区分，不加商品卡框。手机不依赖hover。角色底边光学校正≤4px。

### StampState

输入：label、granted、met、条件说明。granted=true为叶绿实印；未获为砂色淡印，不直接把整按钮opacity降到不可读；met但未入册仍显示未获并说明待同步。印章是无字断墨位图加独立文字，外框100×55左右、旋转-8°。至少44px触区；“收录”与“实践”绑定各自永久事实。所有条件可点开，无重发奖励行为。

### PaperCard

输入：内容、密度、滚动策略。纸材用正式无字RGBA；本轮A/B收敛改用G03独立完整空纸片，保留自然边缘、细纸纹和短接触影，不再用border-image模拟主纸。严禁把整张Mockup当背景。内部按参考锚点留白，内容超高时纸内滚动；滚动容器不剪掉贴纸滤镜。最新尺寸、字体与素材替换以[VISUAL-DIFF-CHECKLIST.md](VISUAL-DIFF-CHECKLIST.md)为准。

### WoodSign

输入：短label、语义状态和动作。独立无字木牌，棕线2.5px，左上柔高光，右下短接触影，保留不完全对称角。文字以安全框居中，不跟木牌被非等比拉长。已选只抬高1–2px与字重，不整块纯黄替代材质。本轮仅规范，不实现生意木牌。

### BasketSlot

输入：真实在售角色、数量、准备／营业状态。器皿后底、角色、前沿三层；空器皿alpha必须完整，角色等比，数量纸签最后叠。单品1个代表，不按数量画角色群；≥4种改两列，不降低角色辨识。不可把鸡宝画死在篮底。本轮仅规范。

### UnknownSlot

输入：可公开线索动作。统一无字未知纸片＋“？”＋“未知”；不使用未发现角色轮廓、blur图或屏幕外隐藏的真实名称。尺寸与已知贴纸格一致，浅砂色、弱内纸纹，无稀有光效。可点击看公开线索，不能灰到像不可交互。

### HelpButton

无字圆纸钮A＋程序“？”U，尺寸44，棕线约2、奶油填充、下缘小影；问号24px。焦点圈独立且对比足够。只解释当前页面；关闭恢复原滚动与焦点。教程不常驻占图鉴主体。

### BottomNavItem

输入：原图标、两个字标签、current、结果点。**取消整格黄色矩形和粗棕底线。** 公共浅奶油底保持完整；当前项图标1.08倍并上浮3px，图标背后一片柔和手绘淡黄／草绿底（宽约44、高28、约60%视觉强度），文字暖深棕/800；非当前图标原比例、文字暖灰/650。命中格仍等宽≥64（320宽五项），高度68–76；图标30–34。选中同时设置aria-current=page，不靠颜色。按下只动图标0.96，不移动命中区；reduce-motion取消位移保留底和字重。先只在Golden Sample作用域使用，其他页面后续确认再统一。

## E. Asset Sheet计划

所有表无界面文字、编号、水印、角色和整页布局。建议RGBA透明底，格间至少32px、外边至少24px，清单记录格位，不在图内标ID。光源统一左上偏前、无硬长投影；切分只做裁切、alpha清理与边界修整，不借代码重新画美术。原始表留存；切图PNG进入manifest并记录sha256、sheet、crop、size、anchor、safeInset、status。未审核标candidate，投入本样板的为golden-sample资产，不自动等于全项目正式验收。

|---|---|---|---|---|

## G. Golden Sample实施与验收门
