## Step 1 · 审计

### 1.1 现在每个页面的结构和点击流程

| 页面 | 结构 | 主要流程（点按次数） |
|---|---|---|
| 寻访·地图 | 地图 + 目的地卡（进入地区）+ 「发现册」「近郊」两个小按钮 | 寻访 → 进入地区 → 选地点 → 选方向 → 准备出发 → 出发 = **6 下** |
| 寻访·地区页 | 去哪里走走（2 个地点）、可以做这些事（补材料/找标本/寻见闻）、本次目标、同行 3 格、保证份数、时长和准备出发 | 同上 |
| 寻访·发现册 | 发现卡数、新品数、标本›辨认›试做、标本卡、见闻与事件、地方做法 12 格、做法详情、替代做法 | 辨认 1 下；设为寻访目标 1 下；研读要先学手艺 |
| 寻访·近郊 | 3 条老路线、同行、保证份数、几率、线索、折叠的偏好设置 | 寻访 → 近郊 → 选路线 → 出发 → 确认 = 5 下 |
| 生意·营业 | 招牌、菜单卡（★）、货篮、订单/常客/项目三个入口、开张 | 生意 → 开张 → 确认 = 3 下 |
| 生意·订单 | 厨房往事卡、进行中 0/2、新的询问（略过/接取） | 订单 → 接取 → 确认 → 交付 → 一键配齐 → 交付 N 只 → 确认 → 关结果 = **8 下** |
| 生意·常客 | 4 位常客格子（未来访、有新故事） | 常客 → 卡 → 读这段 → 收好 = 4 下；**不读就不往下走** |
| 生意·项目 | 一张大卡 + 其他项目列表 | 项目 → 继续筹备 → 登记 → 确认 = 4 下（0 CP 也要确认） |
| 线索册 | 已解锁 / 待推断两栏，调查卡列表 | 图鉴 → 线索册 → 去做/去试 → 下一锅开火 = 4 下 |
| 下一锅 | 多赚 / 交订单 / 新伙伴 / 自己选 4 个书签，一张推荐卡 + 换一个 + 自己推测 | 厨房 → 下一锅 → 开火 = 2–3 下 |

**结论**：

- **留白过多**：账单、订单、常客、项目。这几页是一张大纸只放一两样东西。项目页中间有 200px 的空带，常客页有 128px。
- **文字过密**：寻访地区页（151 字、13 个按钮挤在一屏）、发现册（667 字）、全部出品（28 个按钮）。
- **列表过长**：线索册「待推断」104 只伙伴连成一条 9454px 的长列表，第一屏看不出该先看哪只。
- **主次不分**：
  - 寻访地区页里，「补材料 / 找标本 / 寻见闻」和地点、同行一样大；
  - 生意页里，订单、常客、项目三个入口和营业同级；
  - 下一锅的四个书签看起来同等重要，玩家要自己判断先看哪个。
- **做得好的**：寻访地图（40 字、10% 空白）和营业的货篮。地图和货篮这两块美术是对的，后面的样稿保留它们。

### 1.3 联动断裂点（用你的存档核对过）

1. **寻访给的线索对你没用。**
   - 寻访线索只给「剪影」和「厨具」两层；你学了「风味辨识」，这两层本来就全都看得到。
   - 线索册里一共 104 只：7 只已解锁，7 只能试，剩下 90 只没有任何一条寻访路线还能给新线索（`clueCandidates` 全部为 0）。
   - 所以"缺线索 → 去寻访"这条路现在是断的。
2. **地区的 48 位新伙伴不在线索册里**，单独待在发现册，用"方向 / 完整方法 / 免费 3 趟 / 研读"另一套说法。
3. **下一锅不知道订单**：
   - 只算"已接取"的订单（`openDemands`），新的询问不算，你现在的两张询问都看不到；
   - 也不知道今日菜单缺谁，比如「茶香便当」缺蜂蜜松饼鸡。
4. **内容里早就写好的互相牵引，界面没显示**：
   - 常客「茶坡访客」第 1 段末尾写着"茶叶蛋鸡可以同行，到焙叶棚看看两面叶"（指向寻访）；
   - 订单「茶会添一盘」关联茶坡事件卡 T-E1、常客 RG3 和项目「茶坡一桌」；
   - 「旧厨房老顾客」第 2 段结尾写着"去谷地看看纸包里还能添哪一种麦香"。
   这些都只写在故事文字里。
5. **生意没有给"下一步"**：
   - 开店卖的钱和仓库卖差不多；
   - 项目「我的小店招牌册」第一阶段 0 CP、已经可以登记，主页上看不出来；
   - 常客不读完就卡住。

### 1.4 保留 / 降级 / 重复

- **保留**：
  - 地图与地区美术、伙伴配队与采集/发现数值、材料池；
  - 线索册"已解锁 / 待推断 / 研读 / 去试 / 去做"、第二味由玩家自己推测；
  - 下一锅入口和"只推荐现在能开的锅"；
  - 营业的菜单和货篮美术、订单模板、常客故事、项目、厨房往事；
  - 全部鸡宝生产规则。
- **降级到二级页**：
  - 地点插画和特殊发现收集格（地区详情）；
  - 保底和几率说明（「?」）；
  - 常客、项目（主页只留进度小卡）；
  - 账单（点营业卡看）；
  - 全部出品的细调（换菜单里）；
  - 研读（调查卡上的次按钮）。
- **重复或多余的操作**：
  - 近郊和地区是同一趟行程的两套入口；
  - 选地点 + 选方向（补材料对材料量没有影响）；
  - 订单的接取、预留、确认、关结果；
  - 常客的读这段 → 收好；
  - 0 CP 项目阶段的确认；
  - 四种数量选择器；
  - 发现册"辨认"要手动点；
  - "设为寻访目标"不设就不推进；
  - 四种各算各的保底。

## Step 2 · 玩家流程

### 主循环

```
寻访 ──带回──▶ 材料 · 线索 · 偶尔特殊发现
  ▲                     │
  │                     ▼
情报/新目标        线索册（调查卡：x/5，追踪一只）
  │                     │ 去试 / 去制作
生意（今日菜单、订单）◀─┘  ▼
  ▲                下一锅（为什么做这一锅）
  └──── 新伙伴 ◀────────┘
```

四个系统各管一件事：

| 系统 | 负责 | 给下一个系统什么 |
|---|---|---|
| 寻访 | 发现 | 线索（推进某只伙伴的调查进度一层）、材料、偶尔的特殊发现 |
| 线索册 | 推理和整理 | 一个追踪目标；能试或能做的配方 |
| 下一锅 | 立刻行动 | 新伙伴；订单需要的伙伴；收益 |
| 生意 | 消耗成果，产生新目标 | 订单奖励里的地区情报；常客故事指向的地点；菜单缺的伙伴 |

### 例 1 · 蜂蜜松饼鸡（原版伙伴：线索 → 推测 → 菜单 → 常客 → 新地区）

1. 你现在派去林间茶坡的那队（时空鸡、康乃馨鸡、超大吉签鸡）回来，带回蜂蜜、香草叶、人参。
   - 按新规则，同时带回一条线索：「C122 第一味是面粉」。
   - 原来这趟只会给 C122 的剪影，你早就看得到。
2. 线索册里 C122 变成「调查 3/5」：✓ 平底锅 Lv.2，✓ 面粉。谜语写着"金黄的小圆片，喜欢披上忙碌小翅膀采来的甜"。你点了追踪。
3. 寻访卡上出现"追踪 C122 · 它要的蜂蜜在这里带回"。再去一趟茶坡，读到「第二味是甜味类」→ 4/5。
4. 下一锅顶部第一张卡：「继续调查 C122 · 第二味是甜味类，能试 2 种」。
   - 甜味类里现在买得到的只有巧克力砖和蜂蜜；白砂糖、焦糖浆买不到，不列出来。
   - 你按谜语挑了蜂蜜（家里有 9 份，就是茶坡带回的）。平底锅 + 面粉 + 蜂蜜，开火 110 CP。
   - 这是四时配方，每锅约 25% 出现。
5. 孵出蜂蜜松饼鸡：线索册这一张变成"已收录"，图鉴入册。
6. 生意的今日菜单「茶香便当」原来缺蜂蜜松饼鸡（还缺茶叶蛋鸡、墨西哥卷鸡各 3 只）。凑齐后，菜单里的伙伴卖价 +25%。
7. 「茶香便当」有效接待一次，推进常客「旧厨房老顾客」第 2 段「纸包里的茶香」。
   - 故事结尾："去谷地看看纸包里还能添哪一种麦香。"
   - 情报：谷地早市「麦粒边的一点白」。
   - 寻访地图上谷地亮起提示 → 下一轮从谷地开始。

### 例 2 · 焙叶茶衣鸡（地区伙伴：茶坡 → 订单 → 常客 → 特殊发现）

1. 线索册里 C141（茶坡）已解锁：水煮锅 + 焙香叶。焙香叶你已辨认，商店 25 CP 一份。点「去制作」。
2. 下一锅：「地区试做 C141 · 每锅 25%，连续 3 锅没出第 4 锅一定出」，开火 85 CP。孵出焙叶茶衣鸡（茶味）。
3. 生意订单板出现「茶会添一盘」（茶味 ×6 + 小点 ×6）。常客「茶坡访客」第 1 段要"茶味任选两种各卖至少 1 只，共 6 只"：茶叶蛋鸡 + 焙叶茶衣鸡正好两种。营业卖掉 → 读到「茶香先后」。
4. 故事结尾："茶叶蛋鸡可以同行，到焙叶棚看看两面叶。"
   - 茶坡的地区卡出现"带上茶叶蛋鸡：可能遇到见闻「棚下的两面叶」"。
   - 寻访得到这张特殊发现，开放观赏伙伴 C146 茶芽冠鸡的线索（保温灯 + 焙香叶 + 食盐土）→ 回到线索册。

### 例 3 · 谷棚点心箱（订单驱动：生意 → 下一锅 → 新伙伴 → 谷地）

1. 生意订单板：「谷棚点心箱」小点 0/6 · 家常 6/6，奖励 +18 CP + 谷地情报。按钮是「去做小点」。
2. 下一锅顶部：「订单「谷棚点心箱」还差 6 只小点」。
   - 烤箱 + 面粉 → 约 9 只丸子鸡三兄弟，开火 50 CP（含买面粉）。点「做这一锅」。
3. 收好后订单卡变成「交付」，一下确认 → +18 CP + 谷地情报。
4. 谷地情报推进一只"线索在谷地"的伙伴一层（优先追踪的那只）。
   - 例如 C031 木乃伊鸡宝读到「第一味：防腐剂」，一味配方就此完整 → 已解锁。
   - 下一锅出现「能出新伙伴 C031 · 每锅约 20%」（你家里有 5 份防腐剂）。
5. 谷地还没去过：地区卡写着"第一次寻访会带回入门标本「荠菜」"→ 去谷地。

## Step 3 · 四个页面的信息架构

### 寻访

- **第一层：寻访页**。上方是地图（不改，点地区切换），下方是地区卡。
  - 地区卡依次放：
    - 地区插画、地区名、时长和至少几份材料、常带回的材料图标；
    - 三条进度：伙伴线索 x/12、新食材 x/2、特殊发现 x/4；
    - 一行「最近：…」；
    - 追踪提示（追踪伙伴的线索在这里时才出现）；
    - 同行 3 个头像（点头像换人）+「立即寻访」。
  - **状态**：
    - 未开放：锁 + 条件图标；
    - 可出发；
    - 路上：伙伴在地图上走，卡片显示倒计时，召回放在详情里；
    - 归来：收获卡，包括材料、新线索（写明推进了谁）、特殊发现，按钮是「收下」「看线索」。
- **第二层：地区详情**（点地区名进入）。
  - 两个地点插画；
  - 特殊发现收集格 6 格（标本 / 见闻 / 事件，没找到的显示剪影）；
  - 本地区 12 位伙伴的状态格；
  - 「?」规则：保底、事件要带的伙伴。
- **自动处理**：
  - 每趟自动找本地区还没找到的（先标本，再见闻和事件）；
  - 标本带回自动辨认；
  - 地区采样自动；
  - 沿湾路标在条件够了以后，下一趟溪岸自动找到；
  - 免费方法改为线索推进。
- **合并**：近郊三条老路线就是三个地区背后的路线。近郊页不再是单独入口，它的三个手艺在地区里生效。

### 线索册（调查中心）

- **入口**：图鉴 → 品种 → 线索册；寻访归来「看线索」；下一锅顶部追踪条；订单情报到账提示。
- **页面**：蛋种切换 + 筛选（全部 / 追踪 / 能做 / 能试 / 等条件），追踪卡置顶，其余是紧凑调查卡。
- **调查卡**：剪影、编号、地区标签（地区伙伴才有）、调查进度 x/5、四项清单（厨具 / 第一味 / 第二味 / 其余条件，✓ 或 ?）、谜语便签、按钮。
- **主按钮按状态自动决定**：

| 状态 | 主按钮 | 次按钮 |
|---|---|---|
| 配方完整，现在能做 | 去制作 | — |
| 能推测（条件满足，调料买得到） | 去试一锅 | 去寻访（还能读下一层时） |
| 缺线索，有地区能给 | 去寻访 · 地区名 | 研读 |
| 等条件（节日、厨具等级、厨房等级） | 显示条件，不给按钮 | 研读 |

- **追踪**：
  - 同一时间追踪 1 只，点星切换；
  - 寻访和订单情报优先推进它；
  - 它的线索地区在地图卡上提示；
  - 下一锅「推荐」第一张卡就是它。
- **地区伙伴并进来**：
  - 方向 = 厨具 + 第一味；完整方法 = 已解锁；
  - 地区试做的保底照旧，写在卡上。
- **第二层**：风味观察（现有详情页）。

### 下一锅（目标聚合）

- **书签**：推荐（默认）/ 新伙伴 / 订单 / 多赚；底部「自己选」。
- **推荐页**：顶部是追踪条（追踪的伙伴 + 进度 + 线索册），下面 3–4 张卡。
- **卡片结构**：
  - 理由行：图标 + 一句"为什么做这一锅"；
  - 组合：厨具 + 调料格，缺的标"买"，未知的标"?"；
  - 结果：目标剪影 + 每锅机会、产出只数，或 +CP · 用时；
  - 状态标签：材料齐全，或要买几种 · 多少 CP；
  - 一个主按钮：做这一锅 / 继续推测 / 开这一锅。
- **排序**（每类最多 1 张；同一组合只出现一次，理由合并）：
  1. 追踪的目标：配方完整就"做这一锅"，否则"继续推测"；
  2. 接近完成的调查：能试且第二味类别已知、已解锁能做；
  3. 订单、菜单、项目缺口，包括还没接的订单和今日菜单缺的伙伴；
  4. 已知配方能出新伙伴；
  5. 收益明显较高；
  6. 资源利用（例如家里堆着的调料）。
- **硬条件不变**：条件全满足、调料现有或买得到、CP 够，否则不推荐。第二味永远不替玩家猜。
- **从线索册进入**：带着目标（制作或推测视图），上方是"线索册 · 追踪 C122"，「看推荐」回到默认页。

### 生意

- **第一层：生意页**。
  - **今日营业卡**：
    - 菜单名 + 3 格特色伙伴，缺的格子显示"? 差几只"，点它去下一锅；
    - 「凑齐菜单 · 全部 +25%」标签；

### 已定（2026-10-07 用户回复）

1. 「辨味笔记」保持现在的被动效果，对所有伙伴都生效。寻访发线索时跳过已经知道的层（手艺或别的来源），发这只伙伴下一条真正不知道的线索。
