# 界面参考：别的游戏怎么把“框”变成“东西”

2026-10-03 第三轮调研。上一轮调研（`artifacts/ui-simplify-20261002/game-ui-research.md`）解决的是“少字、一个主按钮、不用表单”。这一轮的问题不同：用户说很多页面“只是加个框放上去，没有设计”。所以这次只看一件事：好的治愈系游戏怎么让一屏看起来像游戏里的东西，而不是网页卡片。

截图来源：Interface In Game 的截图库，看过的有《动物森友会：新地平线》《星露谷物语》《Moonlighter》《原神》手机版。下面都是亲眼看截图后的描述，不复制原图。Game UI Database 和 ArtStation 要人机验证，没有看。

## 八个做法

1. **界面就是世界里的一样东西。**
   - 星露谷的日历是挂在墙上的月历，生日和节日画在日期格里。
   - 委托是钉在木板上的纸条，带图钉，底下有一个“接受委托”。
   - 信是一整张信纸，开头写“亲爱的……”，结尾署名。
   - 动森的里程奖励是一张集章卡，Moonlighter 的商店升级是一张蓝图。
2. **有人在说话。** 动森和星露谷的商店都是店员站在店里，用对话气泡问“要几个？”。数量也是对话选项：“就 1 个 / 来 5 个！/ 算了”。说明文字少了，说话的人多了。
3. **每一类有自己的颜色和花纹。**
   - 动森配方卡的底是叶子花纹；里程卡钓鱼类是蓝色水波，虫类是绿色叶纹。
   - 原神商店用卡底颜色表示贵重程度。
   - 不是所有东西都用同一种米色框。
4. **进度用东西表示，不用进度条。** 里程卡上是一枚枚盖了日期、歪着贴的邮票；星露谷好感度是一排爱心。
5. **只给选中的东西写名字。** 动森图鉴是方格纸上的小图，没有一格下面写字，名字只在选中时浮出一个小签。没收集到的格子是一个淡淡的类别水印。
6. **主角放在聚光里。** 动森的配方详情把成品放在一个暗色、有光晕的小展台里，像商品照片。旁边是材料表，按钮直接写状态：“材料不够！”
7. **清单用点线连到数字。** “树枝 …… 0/5”，数字放在小格子里，不够时变红。
8. **价钱挂在货架上。** Moonlighter 的展台每格下面挂一张纸价签。动森商店的商品摆在半透明的货架面板上，钱包是右上角一个胶囊。

另外，原神的资料库用一圈大圆徽章选分类，选中的放大放在中间；成就分类是一张张盾形徽章卡。

## 落到鸡宝厨房

| 页面 | 现在 | 改成 | 参考 |
|---|---|---|---|
| 订单 | 纸卡片列表 | 木板上钉着的委托纸条：客人头像、要的伙伴贴纸、奖励，纸条可以“接下” | 星露谷委托板 |
| 来信 | 信封格子 / 详情是表单 | 信封有蜡封（没完成）和拆开（完成）两种状态；详情是一封信：“致鸡宝厨房：……”，署名是来信的伙伴，约定写成附言，伙伴照片用胶带贴在信纸上 | 动森明信片、星露谷来信 |
| 收藏回礼 | 进度条卡片 | 集章卡：每张卡有自己的颜色和花纹，格子里盖上已经收录的签鸡印章 | 动森里程卡 |
| 寻宝日历 | 一行行节日 | 挂历：这个月的日期格子，节日伙伴画在日子上，今天圈起来，左右翻月 | 星露谷日历 |
| 小卖部 | 方格货架 | 柜台场景：店员鸡宝在柜台后说话，货物站在木架上，价签挂在下面 | 动森商店、Moonlighter |
| 仓库 | 方格 | 木架：伙伴一排排站在架子上，数字贴在架沿 | Moonlighter 展台 |
| 配方详情 | 图 + 小牌子 | 成品放在小展台的聚光里，调料用点线连到“有/要” | 动森配方详情 |

现成美术件够用的：木板（family-project-board）、图钉（family-pin）、胶带（v2-tape）、夹子（memento-clip、family-clip）、夹板（v2-order-pad）、收据（family-receipt）、信封（precision-envelope-*、family-envelope 带蜡封）、各种印章、挂牌（sign-*）、木条（counter-plank）、篮子、丝带、植物。缺的放进第 5 批：店内背景、店员姿势、挂历框、价签、信纸花纹、集章卡花纹、展台。
