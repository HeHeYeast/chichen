# 1.5.3 手机界面修正

针对 2026-09-30 的实机反馈调整现有界面，不重绘厨房、农场，不改变生产、孵化、资源和存档规则。

## 修改范围

- 厨房：缩短下方备锅区域的冗余高度，场景坐标高度从 757 调整为 720，给主体更多纵向空间。按后续反馈，鸡蛋宽高等比例放大 8%，保留原有每排蛋形；抵消房间随屏幕高度伸缩对蛋的影响，短屏也不压扁。横向中心间距收紧 4%，纵向排距随蛋等比例调整。绘图和点击区域共用映射，已有蛋的存档坐标不变。
- 底栏：手机模式统一为 64 CSS px，另外保留系统安全区；保留五个图标、名称和当前页状态。原厨房约 87 px，寻访约 98 px。
- 生意：长名称独立换行、名牌留内边距、销量汇总容器自适应。紧凑排列订单、常客、项目和账单。项目卡片被旧 `flow-root!important` 样式覆盖，变成图标/标题/箭头竖排，是页面过长的重要原因；现在明确恢复横向布局。原裁切角色 SVG 的可见溢出也已限制在画像范围内。
- 寻访：地图、目的地卡、次级入口改为独立行，取消小屏固定 684 px 地图高度；地区选择、关注、同行、出发按钮紧凑排列。“地区发现”改为“发现册”，记录标本、见闻等地区发现；“旧路线”改为“日常寻访”，仍保留菜园围篱、溪岸小径、林间茶坡三条原采集路线。
- 图鉴：底栏进入图鉴时显式打开总览，不再沿用上次的见闻页。内部深层入口仍能定位对应内容。整体增加页边距、书脊和边框厚度；卡片取消倾斜并为阴影留出空间。
- 回归额外发现：首次进入厨房的补给迁移提示在 900 ms 后无条件覆盖技能回馈。现在只在没有面板、弹窗、其他提示时显示；繁忙时保留未读，留待之后进入。技能用例增加受控时钟显示/到期断言，独立重复三次通过。
