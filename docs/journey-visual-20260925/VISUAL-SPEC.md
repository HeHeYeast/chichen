## 生产与切分

Asset Sheet按类别统一生成，轮廓在300px对象尺度约4px，左上柔光、短暖棕半透明接地影。来源图保留。先按语义槽定位，再按alpha连通区域识别主组件；透明细碎噪点清理；保留对象自身构成与合理阴影；紧致bounds裁切后加入统一安全padding。禁止简单矩形截取带入相邻资产。

每项manifest保存source、sourceCell、sourceBounds、size、visualBounds、anchor、padding、推荐Runtime视觉尺寸。地标和地点底中对齐；图标中心对齐；伙伴垫底中对齐。Runtime按visualBounds使用，不按原PNG空白决定比例。薄边与装饰不随容器无比例拉伸。

## 流程与原业务边界

地图 → 选择/查看地区条件 → 地区内点击地点 → 补材料/找标本/寻见闻 → 同行选择 → 独立出发确认 → 地图在途 → 归来查看实物与新发现。特殊事件仍属于原数据的见闻方向，不另造新的概率类别。

在途路线为表现层，明确不代表引擎新增移动机制。锁定地区可查看缺项，不能出发。空队伍出发禁用。每种留一、上次队伍、地区采样、沿湾路标、带货交换、提前召回、分批领取、只领CP/线索、确认放弃、辨认、研读、置顶方法、试做、地方替代、原三条路线全部保留。

帮助包含当前地区的完整概率/保底/材料容量/方法进度，以及F/G、采样、带货和召回规则。发现卡/标本实名与未知条件沿用regionView和projectMaterial；不因为新画面泄露未发现角色和材料。
