# 当前计划与待验事项

更新：2026-10-10。本页是唯一当前状态入口；已完成轮次的细节见[历史档案](archive/README.md)。

## 当前基线

- Android 发行配置 **1.5.20 / code 36**；241 种伙伴、83 种材料、存档 schema 6。版本号以[发行配置](../android/release.json)为准。
- 寻访 → 线索册 → 下一锅 → 生意的五批实现已完成并随 1.5.19 发布。已保留旧档、永久签名和覆盖更新机制。2026-10-07 有荣耀 Magic8 保档更新及玩法走查记录；不是所有手机的兼容保证。
- Web 新增账号隔离、手动云备份、预览恢复、历史与反馈入口；Node/SQLite、本机 workerd/D1 及隔离浏览器已有 2026-10-08 验证记录。云地址为空、Worker 关闭，未部署线上服务。Android 暂未接入账号层。
- 微信仅有共享规则／Canvas／模拟 wx 存储的独立兼容原型；iOS 只有方案。两者都不能宣称已完成平台移植。

## 下一步

本轮循环调整已完成并打包为 1.5.20：四位人类常客及多轮对话、统一界面、新伙伴推荐、逐枚孵化概率、自动识别素材、两处新增地区、真实库存组合提示均已接入。详见[循环调整与实现记录](design/loop-rebuild-20261009.md)。九类发布门禁和正式签名 APK 构建已通过，未更新手机。

1. 云服务：测试环境获授权后，验证 Cloudflare 免费档密码计算 CPU 与国内网络可达性；线上配置前仍使用[本机联调](../cloud/README.md)。首次付款不超过 50 元、全年成本小于 50 元，不自动升级付费套餐。
2. 面向真实玩家开放账号前，补齐找回／重置密码、账号删除界面、独立备份与灾备恢复演练。接口合同、现有保护和缺口见[云备份实施报告](platform/cloud-wechat-implementation.md)。
3. 微信：取得可用小游戏 AppID 并核实个人主体资质、认证费用和素材授权，再用开发者工具与 Android/iOS 真机验证。步骤见[原型说明](../experiments/wechat/README.md)。
4. 正式发行：按[设备清单](quality/device-release-checklist.md)补足前后台、强退、通知、导入导出及升级矩阵；邀请 3–5 位新玩家检查理解成本与长期节奏。单台走查和模拟不能代替这些验收。
5. 扩展角色美术按[制作规范](art/character-design-spec.md)持续验收，保留原角色身份和已确认画风；概念剪影不等于正式资产交付。原作授权材料见[授权准备](permission-request/README.md)。

## 已确定的规则与范围

- 厨房／农场不重新设计；保留四级厨房、24 枚蛋和已确认的五入口。世界名、前任身份、停业原因和 NPC 私人履历继续留白。
- 线索册追踪普通／地区伙伴；寻访提供下一层线索，订单情报仅来自本地区。新锅逐枚抽取；地区／四时配方采用30%／20%／10%档位，首见与复做一致，同锅可出多只；旧锅按冻结结果结算，不重抽。未收锅不提前揭晓结果。
- 下一锅「推荐」只推荐当前能做的，说明追踪／订单／菜单／新伙伴理由；夜间给出适合放到早上的选择。「新伙伴」另按线索册列出最近目标及可做／试做／寻访／缺条件。生意凑齐菜单时，菜单要求的伙伴这一单加价 25%，多余伙伴按原规则出售。
- 不恢复旧报告中的“等待 Batch 1 确认”“241 种尚未实现”“停在 1.5.1”等任务。当前设计参考[循环调整与实现记录](design/loop-rebuild-20261009.md)，10 月 7 日方案及历史数值只用于追溯。
