# Egg Layout Notes

四级均以自己的参考图逐排测量，使用独立固定坐标模板。没有共用规则 Grid，没有运行时随机 jitter；刷新、收取和升级不重新排剩余蛋。

| Level | 每排顶部 Y（390×844） | 特征 | 精确程度 / fallback |
| --- | --- | --- | --- |
| Lv.1 | 299 / 314 / 330 / 347 | 草窝内较窄、后排收拢，前排 36×34 | 独立测量模板；轮廓接近参考，原稿逐蛋高光 / 细微倾角未逐一保留 |
| Lv.2 | 277 / 292 / 311 / 330 | 木架斜面更深，前排展开至 39×39 | 独立测量模板；不是 Lv.1 模板放大 |
| Lv.3 | 287 / 302 / 320 / 338 | 搪瓷盆前排横向铺开，前排 42×35 | 独立测量模板；前沿裁切保持在盆内 |
| Lv.4 | 299 / 314 / 331 / 348 | 软包内的紧密四排，前排 38×33 | 独立测量模板；背座、软边和厨师摆件保持原稿 |

每级四排，每排六个显式 X 值和独立行尺寸，共 24 个稳定索引；具体坐标在 `GOLDEN_LAYOUTS`。后排先画，前排后画，容器前沿最后覆盖。收取按前到后命中，拖动可连续收取。

不是逐像素复制 24 枚原稿鸡蛋：独立蛋 sprite 来自 Lv.3 前排完整蛋的透明轮廓，按各级蛋位尺寸绘制。它减少了原图蛋之间的自然形状变化。这是单级固定模板的实现取舍，四级没有退化到统一布局。

孵化中的蛋、破壳、伙伴和已收取空位受原引擎控制；24 枚语义由原 `batch.eggs` 保证。显示和点击使用同一坐标变换。存档中的 `x/y`、随机票据、蛋种、厨具、时钟和收取状态不被美术映射改写。

原参考 Lv.1 的“调味 1/3”与现有玩法不符：真实上限为 `min(3, kitchenLevel + 1)`，所以正式 Lv.1 显示 **1/1**，Lv.2 **1/2**，Lv.3 / Lv.4 **1/3**。
