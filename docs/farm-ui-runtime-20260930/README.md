## 保留和补齐的入口

- **修复围栏**：顶部「整修 xx%」可以点击；也可点顶部「农场」打开地点面板，再选「修复围栏」。使用原完好度、原报价和原扣费规则；取消不扣费，余额不足拒绝，满完好度不可重复修复。有伙伴且完好度低于 60% 时，任务条也会引导整修。
- **仓库**：地点卡、建筑本身、顶部在家数量均可进入；保留伙伴明细、可用/外出/营业/预留数量、材料仓库。
- **陈列亭**：地点卡和建筑进入纪念物与三个陈列位，保存后在地图货架上显示。
- **集市**：随拖动进入画面后显示同风格地点卡，也能从标题地点面板定位；保留出售伙伴、经营小店、采购补给、委托与来信。
- **神社**：同风格地点卡、真实可领取状态标记、求签/签册/收藏回礼及原领取限制。
- **码头**：进入原寻访功能。
- **全景与地点定位**：收进顶部「农场」打开的次级面板；常驻只保留右下角放大、缩小、归位。
- **任务条**：空存档前往厨房迎接第一位鸡宝；按实际库存、外出和围栏状态切换引导，按钮实际可用。历史已收集但当前无库存时不会再误报“第一位”。

## 与批准稿的差异

1. 按本轮要求，将地点卡从 **120×46** 缩至 **108×42**，图标从 30 缩至 26 px；仓库左上角约 `(164,193)`、陈列亭约 `(112,469)`，气泡尖角继续指向建筑。
2. 顶部「农场」标题新增次级地点面板交互；顶部在家数量、整修状态和任务条均为可用入口，静态视觉维持批准稿。
3. 数据和任务使用真实存档，因此实际游玩时金币、在家数量、完好度与任务文字会变化；验收图单独使用与批准稿一致的数据。
4. 390×844 下地图取景对齐批准稿；其他长宽比按视口调整取景，地图可以拖动查看。小屏中未显示的地点通过定位面板仍可到达。
5. 新增的神社、围栏、全景图标沿用批准稿图标语言；没有改变主页面视觉方向。
