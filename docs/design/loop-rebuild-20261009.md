# 鸡宝厨房：循环调整与制作计划

更新：2026-10-10。面向实现与美术制作人员；本页记录已定规则、制作沿革与最终实现。本稿覆盖 10 月 7 日方案中与下列规则冲突的部分，旧方案仅供追溯。

## 已定边界

- 下一锅保留推荐、新伙伴、订单、多赚四个界面。推荐现状可用，保留综合推荐、追踪与业务来源；本轮重做新伙伴的目标筛选及排序，不重建推荐体系。
- 厨房、农场、五个主入口与已有伙伴身份保留。功能在游玩循环中逐步开放，已解锁的老存档不重新锁回去。
- 常客改为独立的人类居民。新形象与新界面先做可点击预览，用户已确认第二版场景，沿用现有纸张木牌界面接入；不为常客编造前任身份、世界设定或私人履历。
- 界面文案短、具体；NPC 说自己的需求与反应；帮助分段说明规则、操作、例外。不把教程塞进 NPC 台词，不重复“熟悉的味道、留一点位置”等空泛表达。
- 新发现应立即检查已有伙伴能组成哪些售卖组合，显示实际库存、条件和额外收益。不得拿固定示例冒充唯一配方。
- 地区内容采用基础素材、高级素材与多条相关线索。发现卡不再是玩家必须理解的概念，素材首次获得后自动完成辨认；见闻归入旅途记录，地方做法归入线索册。
- 选择地区时，未发现内容暂按未知格显示，已发现素材可见；地区介绍提供方向，不揭晓答案。当前实现保留未知信息保护，卡片显示两档素材的位置和发现状态。
- 孵化按稀有度分档、逐枚抽取，同锅可出多只。首见和复做一致，取消地区 25% 每锅、第四锅保底、复做固定一只。校准后采用常见 30%、少见 20%、稀有 10%，与普通配方的实际产出接近，不把所有新地区品种设为稀有。

## 游玩流程与开放时机

| 玩家刚完成的事 | 新开放或新提示 | 主操作 | 防止卡住 |
|---|---|---|---|
| 收获多余伙伴 | 普通售卖引导 | 卖出多余伙伴 | 保留收藏与在家数量；不先要求组合 |
| 完成入门生意，满足出行条件 | 常客来访、首次谷地寻访 | 去谷地看看 | 用已有伙伴出行；不依赖未发现地区伙伴 |
| 带回荠菜与线索 | 素材供货、线索册目标、新伙伴建议 | 准备或试做 | 一次结算收下；不另找辨认按钮 |
| 发现荠菜煎饼鸡 | 与库存香煎鸡等搭配的组合 | 去摆货 | 数量够直接摆；不足明确差量；没有搭档给出可达成目标 |
| 完成组合销售 | 常客回应、订单教学 | 接单或交付 | 接单前能看需求；已有库存直接交，不强迫再做一锅 |
| 完成需求／发现当地新品 | 高级素材方向、其他地区线索 | 再寻访或继续经营 | 展示一个清晰条件；不叠加故事卡、标本、次数三种门槛 |

首次引导每次只讲当前操作，允许跳过、帮助可回看。已完成的事实直接追认；不要因为未点“收好”而挡住所有后续功能。寻访等待不阻塞厨房或营业。发现通知按一次收锅合并，避免逐只弹窗。

## 下一锅与线索册

新伙伴从线索册未发现条目产生，复用其追踪、可做、可试、可寻访和条件排序。一次列出最多五个目标，显示已知线索、缺少条件和一个主操作。未知名称、配方和未获得的剪影不得提前展示；新发现从列表退出；正在锅里的目标提示收取，不暗示抽取结果。

推荐保留当前综合逻辑。同一配方兼顾订单和收入时保留一张卡并显示补充理由。订单和多赚保留各自目的，统一显示耗时、成本和收益口径。手动调味与商店显示与线索一致的分类标签；推测第二味时按该类别筛选。

## 新界面与美术

### 预览与确认记录

最初比较营业场景底部交谈与独立来访页两种布局，演示对话 → 地区提示 → 收获 → 组合解锁 → 摆货。用户随后确认四位常客的第二版完整场景和多轮对白；最终沿用原游戏纸张木牌样式。早期候选保留供追溯，不再等待选型。

### 最初素材规划（实际交付见本轮实现）

| 资产 | 数量与用途 | 制作边界 |
|---|---|---|
| 常客立绘 | 老顾客、溪边采购人、茶坡访客、沿湾货客，各一张主立绘 | 人类、稳定站姿、少细节、棕色轮廓；服装与道具区别身份 |
| 常客背景 | 小店门前、溪岸歇脚处、茶棚檐下、沿湾装货处，各一张 | 用户已确认每位常客独立背景；无人物和文字，人物叠加，不增加寻访地区 |
| 常客表情 | 每人普通、提出需求、满意三态 | 同一角色编辑扩展，不能每张换脸 |
| 常客头像 | 从确认的主立绘适配头像槽 | 48/96 像素检查、透明边缘检查 |
| 对话界面 | 姓名牌、对话纸片、动作区 | 文字用界面渲染，不能烘焙进图片；优先复用现有组件 |
| 组合解锁 | 伙伴并排、组合名、实际增益、去摆货 | 用已有伙伴图，未知伙伴不露图；不用新的“组合卡”货币 |
| 地区扩展 | 现有四区先简化，再扩展两个地区 | 新区需有两种素材、至少三条配方线索；资源与厨具门槛核算后再制作地图插画 |

现有谷地荠菜／麦芽、溪岸山柚／水芹、茶坡焙香叶／桂花、风湾盐花／海蓬菜保留身份。基础／高级归属按各区首个可做配方决定，不能仅凭价格分类。新地区不通过增加概念来增加内容。

### 文本示例

- 界面：新组合可上架；还缺香煎鸡 ×2；下一条线索在谷地。
- 老顾客（短、直接）：我刚从谷地回来，荠菜已经上市了。你要做荠菜饼的话，明早给我留一份。／就是这个味儿。再给我装两份，别捂严了，饼皮会软。
- 溪边采购人（在意携带和份量）：分两个包，别压在一起。／这份不漏汤，带去溪边正好。
- 茶坡访客（在意味道和搭配）：茶味留着，再添两份不太甜的。
- 沿湾货客（在意装箱与路程）：这箱路上要颠，软的放上面。
- 帮助分“怎么搭配”“什么时候加价”“库存不够怎么办”，显示实际规则与例子；与 NPC 台词分开维护。

## 实施顺序与验收依据

以下是本轮执行依据，完成范围见下一节；其中先做候选、等待视觉选择的阶段已结束。

1. **候选界面与美术**：生成老顾客立绘、可点击两种布局；手机宽度 320/390/430 验证。用户选定后扩展其余常客。候选资产不直接替换正式角色。
2. **新伙伴及调味**：复用线索册排序，加入地区目标、条件与跳转，显示调味类别；保持推荐、订单、多赚行为。验证未知信息不泄漏、已发现退出、缺钱／缺材料／未收锅、两种蛋。
3. **孵化概率**：统一本次改动涵盖的普通、蒸笼、四时、地区抽取口径与预估。明确稀有度数据；新规则只影响新开的锅，旧锅按旧票据收取。验证保存恢复、24 枚总数、多只目标、首见复做同概率、模拟均值和空锅率。付费复刻等显式奖励单独核查并同步描述，不能留隐藏“必出”入口。
4. **首次引导与组合**：在收获、营业结算中产生引导事件；按库存找有效组合并显示真实加成。解锁、关闭、重开、跨存档与旧档迁移均要验证。当前实际组合完整加成是 25%，早期讨论中的 8% 是旧内容表值，预览与实现不沿用它。
5. **常客与寻访**：接入已确认的形象和对话组件，分离台词与规则提示；减少重复点击，素材自动辨认、结果回到对应线索，新旧记录兼容。
6. **扩展与发行**：增加地区及内容后验证无循环解锁依赖；完整回归、隔离新档/中期档/老档浏览器走查、手机视口、素材大小与字体字库。此后再构建安装包，未构建不宣称已更新手机。

## 本轮实现（2026-10-10）

用户已确认第二版背景、人物及对白；原型和正式界面共用游戏既有的纸张、姓名木牌和按钮。四张含人物的独立场景已注册为正式资源；初访对话和营业／订单之后的故事分开，避免“刚讲采菜，下一句却要求茶会采购”的跳转。

| 范围 | 实现 |
|---|---|
| 下一锅 | 保留四页与推荐主体，新伙伴最多五个目标，沿用线索册排序；缺钱、缺线索、未收锅分别给出实际下一步 |
| 调味与文字 | 手选、商店、详情、线索使用同一类别；16段常客、12个订单、8张菜单及分段帮助已改写 |
| 孵化 | 普通池逐枚抽取，地区／四时采用30%／20%／10%分档；无固定插入、无新锅数保底；旧版本已启动锅结果不变 |
| 生意 | 按可售库存找菜单替代组合，新发现提示可以搭配的菜单，完整组合实际加价25% |
| 首次引导 | 来访→寻访→配方→组合→订单，按已完成事实显示，可关闭，不重锁老档 |
| 寻访 | 归来自动识别素材并开放线索／供货；地区卡展示两档素材；内部旧记录身份保留 |
| 地区扩展 | 果园小径：柠檬／柳橙；山间菌圃：生姜／香菇菌种包。各有多条相关线索，复用已有伙伴与素材身份 |
| 存档 | 新地区行程、逐枚概率票据同步Web与Android校验；旧锅、旧在途与未领奖记录继续结算 |

概率验证使用实际采样函数，三个档位共9000锅，检查平均产量、空锅比例、多目标及首见复做一致；原生存档行为验证已通过。正式发布状态、完整门禁结果与待验设备范围统一记录在[当前计划](../plan.md)，不把历史原型测试当成本版本发布证明。

当前概率档位由最低厨具等级和配方复杂度派生：Lv.3为10%，Lv.2或多味配方20%，其余30%。没有新增极低概率档。平均出货不是承诺每锅必出；旧单候选配方仍可能只出一种伙伴。

新增地区采用旧素材图标，不新增两套区域场景美术。寻访线索保护与孵化概率分别处理；前者仍保留，后者不再累计锅数。背景概念稿和第一版素材保留在原型目录，APK只收录正式注册资产。
