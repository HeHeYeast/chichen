# 界面视觉语言（组件规范 v0）

2026-10-02 起，所有玩家界面按这份规范做。依据是用户认可的四个样板界面：

- 生意店面
- 图鉴 · 收藏
- 寻访地图
- 农场地图

数值都是从样板实测的，不是凭感觉定的。新界面上线前，要和样板放在同一张对比图里自查（见第 8 节）。

## 1. 样板与反例

| 用途 | 样板（对齐它们） | 反例（不要再出现） |
|---|---|---|
| 主页面 | 生意店面、图鉴 · 收藏、寻访地图、农场地图 | 收成 · 细分安排、仓库 · 按数量卖（“前端新手作业”） |
| 弹窗 | 仓库 · 卖掉多余、仓库 · 单只伙伴 | 开火确认（纯文字堆叠）、厨房升级（大片留白） |

截图在 `artifacts/ui-simplify-20261002/shots2/`。用户的逐页批注存在审查页的数据库里（`reviews` 集合）。

## 2. 画风与配色

画风是手绘卡通。

- **描边：** 深棕描边 `#4f2f12`，在 400px 的部件上约 10px 粗，所有部件粗细一致。
- **上色：** 平涂加一层柔和暗面，左上角一点高光。
- **不要：** 渐变、塑料感、发光。

| 角色 | 颜色 | 暗面 |
|---|---|---|
| 纸面 | `#f8f0d8` | `#e8d0a8` |
| 木头（主按钮、牌子） | `#f0b868` | `#d09850` |
| 鼠尾草绿（确认、选中、寻访） | `#a0b880` | `#6f9150` |
| 叶绿（印章、完成） | `#509050` | — |
| 珊瑚红（提醒、活动、推荐） | `#f88058` | — |
| 金（星级、金币） | `#f2c14e` | — |
| 字 | `#5d4026` 主文字，`#8a6a45` 次要 | — |

## 3. 字体与字号

样板页只用两种字体，并且都是粗字：

- **Chicken UI：** 字重 800–900，用于数字、按钮和标签。
- **Golden Display：** 手写感标题字，用于页面标题、卡片名和书签。

| 级别 | 字号 | 用在 |
|---|---|---|
| 页面标题 | 28–36px | 顶栏「生意」「图鉴」 |
| 卡片标题 | 22–24px | 「家常小铺」「街坊早饭册」 |
| 主按钮、大数字 | 19–22px | 「开张」、收录数 |
| 标签、名字 | 15–18px | 伙伴名、书签、按钮下的字 |
| 角标数量 | 13px | ×48 |

**不再使用：** 11–12px 的灰色说明文字。说明要么变成图标加数字，要么收进「?」图卡。

## 4. 文字量

- 样板页首屏约 18–20 段文字，每段不超过 8 个字。正文句子为 0。
- 一页最多一段连续文字，不超过 2 行（约 40 字）。超过的部分改成图标加数字，或者收进「?」。
- 按钮不超过 4 个字。

## 5. 间距（硬规则，机器检查）

- 同级的框之间至少 5px。书签、胶囊按钮之间至少 6px，卡片之间至少 8px。
- 框到外层框的内边，至少 6px。外层只有下边线时，也要离开那条线。
- 文字不能被盖住，不能超出它的框，页面不能截断。
- 例外只有三种：
  - 关闭按钮压在角上；
  - 底部抽屉贴屏幕边；
  - 农场头像的等级牌（用户已认可）。

| 次按钮、胶囊 | `golden-business/v2-wallet.png`、`summary-label.png` |
| 标题牌 | `golden-business/sign-prepare.png`、`sign-open.png` |
| 纸面 | `golden-collection/v2-paper.png`、`golden-business/family-receipt.png`、`v2-order-pad.png` |
| 书签 | `golden-collection/v2-tab-current.png`、`v2-tab-idle.png` |
| 印章 | `golden-business/family-stamp-*.png`、`golden-collection/stamp-*.png` |

第 1–3 批新美术件（见美术件清单页）补上这些部件：

- 通用纸面板、挂牌标题、三色丝带；
- 关闭/返回按钮、加减和快选木币；
- 数值小牌、进度条、方格的五种状态；
- 分隔线和点缀；
- 32 个图标和试点插画。

## 7. 交互

- 一屏只有一个主按钮，次要操作用文字链或小牌。
- 进来时已经按推荐填好，玩家只改想改的。
- 数量不让玩家逐个加：用快选木币（1、一半、全部、留 1），或者拖动木珠，加减号只做微调。
- 玩家界面不出现勾选框、下拉框和输入框。偏好统一放进设置。

## 8. 六类界面的版式

| 家族 | 版式 | 包含 |
|---|---|---|
| 弹窗确认（试点） | 挂牌标题 → 主图（厨具、插画或前后对比）→ 一行数值小牌 → 一个主按钮加一个次按钮 | 开火确认、照顾小厨房、厨房升级、修复围栏、出发确认、这一篮 |
| 清单与商店 | 书签 → 筛选木币 → 方格货架（每格：图、名字、价签）→ 点开底部抽屉 | 商店三页、配方、四时手记 |
| 库存格子 | 书签 → 方格（1:1，不再细长）→ 底部一个主按钮 → 单格抽屉 | 仓库伙伴、仓库材料、陈列亭 |
| 详情与档案 | 大图 → 名字牌 → 2–3 枚数值小牌 → 一段短文 → 去处按钮 | 品种详情、锅具详情、调味料详情、常客详情 |
| 报表与结算 | 丝带标题 → 收获图（伙伴或材料）→ 一行数值 → 一个主按钮，不需要滑动 | 收摊报告、寻访归来、账单 |
| 选人与出发 | 地点图 → 三个坐垫位 → 一行时间和收获预估 → 出发 | 地区、近郊、选伙伴、出发确认 |

## 9. 自查流程（每一版都跑，全部为 0 才给用户看）

组件写在 `web/ui-kit.js` 和 `web/ui-kit.css`。写在美术件上的字一律放进 `[data-safe]` 框，这个框按美术件实测的板面范围摆放：

| 美术件 | 板面范围 |
|---|---|
| 木牌 `ui-kit/plank-board.png` | x 12–88%，y 12–74% |
| 按钮 `v2-action.png` | x 12–88%，y 12–84% |
| 名牌 `precision-exact-nameplate.png` | x 8–92%，y 18–80% |
| 数值牌 `v2-wallet.png` | 字离上下各 14% 高，离两端各 30% 高 |

弹窗、抽屉的检查脚本是 `artifacts/ui-design-20261002/pilot/game-check.mjs`。打开真实游戏，用玩家存档，在 320×568、359×760、430×932 三种屏幕上逐个检查：

1. **字不超出板面，并且在正中：** 用「有字 / 无字」两张截图对比像素（`center_check.py game`），水平误差不超过 1.5px，垂直不超过 2px。
2. **不伸出、不被裁切：** 只有弹窗正文可以在矮屏上竖向滚动；滚动时底部渐隐，其余任何裁切都算错。
3. **一行对齐：** 同一行的图中心在一条线上，说明字在一条线上，按钮行不能折行。
4. **位置：** 弹窗只放在场景顶栏下面、底栏上面，不压住「鸡宝厨房」「农场」这些顶栏，也不半盖文字。
5. **看得清：** 文字和它实际背景的对比度至少 3:1。
6. **整体检查：** 运行 `node artifacts/ui-simplify-20261002/audit2.mjs`，检查遮挡、出框、框贴边（≥6px）和框贴住（≥5px）。
7. **观感关：** 和样板拼成对比图，逐项打分（1–5 分），低于 4 分的先返工，再给用户看。
   - 美术件：有没有手写框？
   - 图文比例：有没有句子堆积？
   - 层次：主按钮是否唯一？
   - 密度：有没有大片留白，或者需要滑动？
   - 对齐：同类元素是否同一边线？
8. **用户审查：** 发审查页，读取批注后进入下一轮。
