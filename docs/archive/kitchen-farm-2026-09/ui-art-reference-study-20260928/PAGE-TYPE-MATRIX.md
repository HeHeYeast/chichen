# Page Type Matrix

研究日期：2026-09-28。读者：后续合并历史 Forensics 的设计与制作人员。用途：确认哪些页面类型已经有证据，以及每种页面如何分配主体、操作、入口和美术。

证据 ID 对应 [Reference Atlas](atlas.html) 与 [完整索引](evidence-index.csv)。**实机**只表示图像来自游戏运行画面，不表示本轮亲自操作验证。**局部**不支持整页布局结论。**缺证**不是该游戏没有这个页面。不同来源、版本不合并成一个假想版本。

## 覆盖判定

矩阵覆盖了每款主要参考游戏的 11 种类型，但没有伪装成 100% 截图齐全。塔塔的商店、真实图鉴、完整任务和角色成长链，以及妙奇的纯净主场景、完整总图鉴、设置和当期活动，仍需手机补证。详见 [Missing Evidence List](MISSING-EVIDENCE.md)。

静态证据可以检验轮廓、密度、信息顺序和组件复用；无法证明触摸范围、弹层动画、页面回退栈、留存或点击效率。报告里对体验改善的描述是设计假设，不是已完成的用户测试。
