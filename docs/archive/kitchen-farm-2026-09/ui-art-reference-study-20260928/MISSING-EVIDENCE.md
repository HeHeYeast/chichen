## 截图随附的最少信息

- 游戏名、国服/国际服或渠道、版本号（能看到时）、截图日期。
- 页面从哪里进入，例如“营地 → 塔塔 → 猫冰 → 进化”。
- 当前状态：空闲 / 进行中 / 可领取 / 锁定 / 材料不足。

保留完整屏幕，尤其是顶部资源、底栏、关闭与返回。可以遮住昵称、UID 等个人信息，但不要遮 UI 边界。原图优于带箭头的拼图；如果是拼图，请说明哪些标记是后加的。

若需要补证 Drawer/弹窗/返回关系，可用“打开前 → 打开后 → 关闭后”三张连续截图；只有静态单张时，仍不判断动画和手势。

## 鸡宝厨房自身的剩余证据边界

本轮不需要为了研究额外操作 Runtime。已使用对应页面族的浏览器截图留档，包含营业/待开张、地图/地区/归来、已收集/全未知/印章状态。

与历史 Forensics 合并时，需要确认这些截图中哪一版对应最终认可版本，尤其是生意三篮布局、寻访精调稿和收藏细节修复稿。单独的账单、订单、项目只是辅助样本，不自动继承主页面的审美确认。
