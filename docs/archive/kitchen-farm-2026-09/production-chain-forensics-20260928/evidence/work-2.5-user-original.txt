==================================================
四、重新审视整个游戏的页面数量
==================================================

当前Work 2统计了56组可达页面/状态。

这不代表一定有56个独立页面，
但当前整体仍存在：

【子页面和Full-page Navigation偏多】

的问题。

不要简单设定：

56 → 某个固定数字。

真正目标是：

【减少不必要的Full-page Transition和Navigation Depth。】

重新遍历所有当前可达功能。

对每个页面/子页面判断：

A. FULL PAGE
确实值得独立页面。

B. OVERLAY / SHEET
应该作为当前场景上的：
- bottom sheet
- drawer
- modal
- overlay panel

C. INLINE
应该直接嵌入当前页面/场景。

D. MERGE
可以与另一个页面合并。

E. REMOVE NAVIGATION
功能保留，但不需要独立导航层级。

==================================================
五、Scene-first原则
==================================================

厨房和农场尤其遵循：

【Scene First, Menu Second】

例如：

厨房中的：
- 调味料
- 清洁
- 厨具
- 简单库存操作
- 状态查看

优先考虑：

点击场景物件
→ 当前画面展开小面板
→ 完成操作
→ 关闭

而不是：

点击
→ 整页跳转
→ 操作
→ 返回。

农场中的：
- 修缮
- 神社入口
- 收成
- 纪念物
- 状态

也做相同审视。

但不要机械地把所有页面改成弹窗。
