## 一、Kitchen：制作两个完整结构候选

只制作：

### K1 — 蛋窝中心 + 底部工作台

核心原则：

- 自然错落的大蛋窝继续占据主视觉；
- 蛋窝附近直接表达当前批次状态：
  - 空锅
  - 孵化中
  - 部分可收
  - 全收完
- 下方形成一个明确的“下一锅工作台”；
- 工作台承载当前厨具、已选材料以及当前阶段的主要操作；
- 商店 / 仓库 / 手艺 / 帮助不再四个等权常驻；
- 清洁度降级为环境状态 + 轻量操作；
- 收完后的“安排收成”从蛋窝 / 篮子语境中出现。

### K3 — 阶段焦点切换

保持同一个场景骨架，但底部主要操作区随阶段改变：

- 空锅 → 准备下一锅；
- 孵化中 → 倒计时 / 提醒；
- 可收取 → 收取状态；
- 全收完 → 安排收成。

厨具与调味必须仍然可找到，不能因为阶段变化而失去可发现性。

K2 不做完整第三方案，但可以吸收它“调味罐 / 清洁用品 / 篮子作为场景对象”的优点。

## 二、Farm：制作两个完整结构候选

- 农舍段
- 集市段

- 农舍 → 收成；
