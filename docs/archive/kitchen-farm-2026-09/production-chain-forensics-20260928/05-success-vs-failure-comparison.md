# Success vs Failure Comparison

核心对照成立在“同样拥有生成工具，但定义的对象、保留的约束、产物所在阶段与验收对象不同”，而不是“一个写了cozy，另一个没写”。成功和未通过的29个案例均使用[同一12项生产链模板](02-forensics-master-table.md)。以下是跨案例结论。

## 1. 先消除错误前提

成功页面有**整页概念图获认可**，没有证据支持其正式 Runtime 是未经拆分的“完整AI页面背景”。用户在 09-24 19:49 与20:02反复明确禁止此做法。实际记录也显示：生意空篮分前后层、图鉴纸/章/角色独立、寻访地标/环境/路线/动态文字分开。

成功不是零返工。图鉴首版被要求继续收敛；生意修改过框体、阴影、账单位置与子页；寻访首次声称可通过后被用户撤回，进入另一个高精度复刻会话。只比较最终成功PNG与厨房失败草稿，会漏掉这条关键生产差异。

证据：[d334 / 136、215、504、861、1602、2100、2653、2710](evidence/01a0d334-messages.md)，[寻访精确来源](../../../journey-visual-20260925/asset-sheets/PRECISION-PROVENANCE.md)。

## 2. Prompt 层：比较真正要求生成什么

|问题|成功记录|Kitchen / Farm记录|可支持的结论|

**可复核的文本量：** IG054/055/056 共有5,356字符前缀，占各全文约73.5%–79.7%；IG058/059/060共有5,074字符，约68.3%–86.9%；IG076–079共有3,239字符，约68.3%–71.2%。这是工具记录 Prompt 的逐字符前缀统计，**不是风格相似度或失败概率**。共同功能约束本身合理；问题在于共同部分还锁进了室内组织、配色、位置/留白等关键视觉变量。原始Prompt见[档案](04-imagegen-prompt-archive.md)。

“cozy”一词在部分指令里是禁止项，在四级别墅与壁龛描述中又是正向形容。不能按关键词出现次数判断原因。真正有证据的冲突是具体空间构图与用户期望的玩法主体之间的错位。

## 4. ImageGen 层：哪些是实证，哪些只是可能

1. **Style Test 的连续 edit 是实证。** 先各生成A/B/C，蛋数不一致；A两次局部修改后，IG063锁A转B，IG064锁B转C。Prompt要求保留物件、构图、文字、24蛋。最终C虽然平涂，仍有窗帘—柜子—圆桌腿—地毯。这里可说“执行设计保留了旧结构”；无需假设模型自发锁死。
2. **Background A–D 的收敛不是同一条连续 edit 链。** 四张共用5参考；D最终重生成仍用原5参考。相同色板、安全区域、木房身份与旧/负向厨房图形成共同约束。是否负向参考也产生视觉吸附，只能标 **I：可能因素**，没有移除该参考的受控实验，不能定量归因。
3. **成功页同样使用 reference 和 edit。** 生意/图鉴用真实角色纠正；素材表用确认Mockup统一风格；寻访部分最终组件更直接来自原稿提取。因此“强reference/多轮edit必失败”被成功样本反驳。
4. **许多环境细节并非模型无端补齐。** Kitchen Work明确要求圆桌、完整墙面、窗口/壁龛、推车；Style把地毯和桶列入保留物件。Farm IG052直接要求石水盆与小雏菊。模型可能发挥细节，但不能把可追溯的人为要求统称模型自动加戏。
5. **“Game Asset Composition”是画面风格名，不是自动拆层。** IG063仍返回一个完整页面PNG。直到独立Asset Gate才有真实透明对象，且蛋窝B单看通过、实际叠旧蛋却遮挡。名字不能替代可组合性证据。

## 6. 蛋窝回退：完整可核证的非生成失误

用户现在强调的是**紧密、自然错落、互相遮挡的一大窝蛋**，不是“单个蛋图没变”或“总数仍24”。

[K1/K3 prototype.js](../../../../web/prototypes/kitchen-farm-architecture-gate-20260928/prototype.js)第20–24行：`row=Math.floor(i/6), col=i%6`，偏移数组只有少量像素。[style.css](../../../../web/prototypes/kitchen-farm-architecture-gate-20260928/style.css)用 `left: col * 16.3%`、`top: row * 25%`，形成6列4行。aria-label仍写“自然错落的蛋窝”，与可见结果不符。

[原版Before](../../../../artifacts/kitchen-remaster-lv2-20260927/before-lv2-390x844.png)的蛋群紧密重叠；[K1孵化图](../../../../web/prototypes/kitchen-farm-architecture-gate-20260928/evidence/k1-incubating-390.png)明显留出行列间隔。[Work2.5图](../../../../artifacts/scene-first-review/main-scenes.png)也出现规则三行。相反，K13虽整体未通过，却保留了原蛋位，还因遮挡淘汰新窝B：它在这一约束上做对了。

因此责任不能归给ImageGen，也不能笼统说“所有后期版本都毁了蛋窝”。具体失败是**复用了资产文件，却重写了已获认可的组合关系**。旧验证记录报告零溢出/截断/小按钮，并没有验证群形与遮挡保真；工程PASS与审美回退同时成立。
