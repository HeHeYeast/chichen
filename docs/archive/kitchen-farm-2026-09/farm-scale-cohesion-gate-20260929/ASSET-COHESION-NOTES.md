# Asset Cohesion Notes

## 这轮修了什么

| 对象 / 维度 | 上轮的问题 | 本轮具体处理 |
| --- | --- | --- |
| 鸡宝 | 50–52 px，几乎和摆件、门洞同级 | 原角色图不变，可见高度 24–27 px；身体大小由原图裁框计算，保留品种比例 |
| 四建筑 | 分两个小样，无法判断同屏层级 | 同屏统一：农舍 156、补给 114、神社 109、陈列 130 px 宽；保留各自屋顶、门口和功能轮廓 |
| 视角 | 各物件的地面关系缺少统一校准 | 沿用四建筑的屋顶 / 正面 / 右侧面关系；木凳、盆、石、栏均保留顶面与高度；竖线直立，不加消失点，不镜像光向 |
| 树 / 灌木 | 稀疏独棵、硬三角与简单云朵，看起来像地图图标 | 重绘有转折的团簇轮廓、底部暗面和少量顶面亮块；深浅绿不混入建筑黄红；树簇交错并在屏幕边缘裁切 |
| 木凳 | 60 / 58 px 宽，大小与结构都太抢眼 | 37 px 宽；与补给 / 陈列木材使用蜜黄顶面、暖木正面、棕侧面；外线按显示尺寸补偿 |
| 水盆 | 45 / 42 px 宽，冷灰轮廓像单独的金属图标 | 25 px 宽，改暖砂陶盆色；水面保持小面积青色；有盆沿、前壁和右侧暗面 |
| 营火 | 尺度未与角色统一，中心容易越堆越满 | 核对板宽 24 px，暖色大火焰 + 两根木料；本视口不摆放 |
| 石头 / 围栏 | 体量大、栏杆接近角色高度块 | 石 22–27 px，栏段 45–52 px；石用三面、栏用木材统一三色，减少内部线 |
| 描边 | 原 SVG 的同一源笔宽经任意缩放，小件会变细 | 大植被外线显示约 2 px，小件约 1.4–1.8 px；内线约 0.7–1 px。按对象类别做光学校准，避免小件全部变成细线 |
| 投影 | 椭圆最小高度 6 px，缩小对象仍会留下大投影 | 去掉 6 px 下限；小件约 2–3 px，建筑约 5–7 px；统一右下偏移、低透明度，无模糊光晕 |
| 地面 | 大路条、独立多边形斑块，小样各自成岛 | 连续草地 + 主路 36 / 连接支路 30 / 门前短支路 26 px + 林缘底色，完全由 SVG 绘制；道路从下方分流接到四个入口 |

透明建筑使用上一轮已采用的四张独立 PNG，**没有生成或编辑任何整场景图**。环境是重新编写的十二个透明 SVG 模块，角色来自现有项目；16 个资产不含角色与 UI。建筑文件原字节不变，没有通过调色滤镜遮掩差异。

## 实际尺度检查

农舍门洞约 44 px，鸡宝 24–27 px：一只角色小于门洞，进屋语义成立。农舍整体高约 130 px，角色只占其约五分之一。木凳宽 37 px、盆径 25 px，退为生活小件；凳子和水盆分别挪到道路外侧，避免占路与占中央净空。

脚点决定前后遮挡。建筑和环境没有各自独立的“置顶”规则；只有建筑名称为界面叠层。上沿树木采用交错成簇，左右与下部边界延伸出画面。这个测试视口没有实现世界边界、可走区域或镜头系统。

## 与上一轮简短对照

- **场地更开阔：是，相对角色而言。** 同样是 390 × 844，鸡宝身高减半，单屏从两建筑提升为四建筑，活动范围约 220 × 210 px。不是宣称比上一轮截图拥有更多物理像素。
- **角色缩小：是。** Test A/B 的 50–52 px → 24–27 px，约减小 46%–54%；5 只角色以场景单位出现。
- **建筑与摆件更统一：有所改善。** 比例、木材色域、盆材质、显示线重、短投影一致性更强。四建筑的少量原画渐变、树冠与建筑的细节差异仍可见，不能声称完全同一制作工艺。

## 仍需保留的判断边界

四建筑不是同一三维相机导出的模型，倾角只能视觉校准，未做几何重建。原画建筑残留渐变和局部线重差异没有消失；本轮能减少素材不搭，不能证明最终美术已达到塔塔质量。角色已读得出种类，但手机实机上 24 px 角色的表情可读性，以及点击目标应否独立扩容，留到后续交互验证，不在此轮做 Runtime。
