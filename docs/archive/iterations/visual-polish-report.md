# 鸡宝厨房 · Visual Polish / Game UI Pass

> 历史记录：保留当时的决策与验收证据；文中的“当前／待确认／未实现”仅指记录当时。现在的状态以[当前计划](../../plan.md)为准。

日期：2026-09-24。范围：在上一阶段 regression 修复的工作区基础上优化已有界面，不新增经营系统，不修改经济数值、配方、存档 schema 或奖励规则。

## 修改前的主要问题

- 成熟场景与新增系统脱节。厨房、农场、原品种和手艺已有绘制资源，但地区材料、标本、见闻、纪念物缺少图像。
- 48个地区新品种共用一个概念剪影，已收录后仍难以分辨；8种材料也没有各自的物件图。
- 寻访的候选条件、标本说明、免费方法与故事大量平铺；玩家要先读长段落才能判断状态。
- 发现成果和普通文本提示相近，缺少“新伙伴被收入图鉴”的可见反馈。
- 各系统的边框、间距、锁定/选中/已完成状态不一致；桌面便签整列空白，窄屏和横屏的固定控件抢占正文。

详细 A/B/C/D/E 审计及九类资产盘点见 [visual-asset-inventory.md](../../quality/visual-asset-inventory.md)。此次审计同时检查了生意、订单、收藏、常客、项目、神社、旧委托与四时内容。

## 修改后的视觉结构

### 统一设计语言

采用“厨房绘本与寻味手账”：奶油纸、暖棕线、草绿完成态、蜂蜜黄主操作。保留厨房与农场的既有主体画面。共享 token 与样式集中在 `web/visual-polish.css`，在既有响应式修复之后加载。

- 页面外框18px、内容14px、按钮10px；小印章与状态条使用更紧凑圆角。
- 统一层级、边框、轻阴影、焦点环、hover、按下与 disabled；状态同时有文字/符号，不只靠颜色。
- 图鉴采用收藏格，商店保留木货架，发现采用标本/印章/折叠笔记，手艺采用图形徽记和紧凑效果。减少所有系统都像通用网页卡片的观感。
- 操作延续至少44px触控目标；正文可滚动。横屏地区册整体滚动，避免固定筛选区挤没正文。减少动态效果偏好下关闭CSS动画与过渡。

### 各页面

| 页面 | 现在先看到什么 | 详情如何出现 |
|---|---|---|
| Kitchen | 实际已选食材摆上墙架、脏污条、孵化计时、可收取闪点 | 点厨具进入原确认；候选/保护仍可展开 |
| Farm | 场景、在家数量/品种牌、维护进度、真实纪念物陈列图 | 点建筑/收成表管理；没有虚构采集作物 |
| 图鉴总览 | 图鉴与鸡宝封面、收录条、少量后续方向 | 进入品种档案/目标页 |
| 品种 | 画像、编号、状态、稀有程度或地区标签 | 打开档案查看做法和用途；未知内容继续遮蔽 |
| 材料 | 物件图、名称/未知状态、认识流程 | 展开食材笔记，进入关联标本与做法 |
| 手艺 | 方向图标、Lv.0/1、当前学习进度和3项效果 | 点手艺看完整效果/条件；后续手艺折叠；方案确认机制保留 |
| 寻访 | 对应地区小景、目的地、关注方向、同行画像 | 候选卡与概率条件折叠；实际返程后展示材料篮和发现章 |
| 发现册 | 标本图、记录印、地区进度、已收录伙伴 | 点击展开见闻与事件；方法网格选择详情 |
| 商店 | 货架、不同商品图、持有量与价格 | 查看用途/解锁条件，仍使用原购买确认 |
| 收藏/项目 | 书册图标、阶段印记、项目徽记 | 进入进度明细；纪念物可陈列到农场 |
| Settings | 清晰的设置组与折叠内容 | 备份导入导出等原操作不变 |

稀有 badge 只对已知原物种按照原始 `rate` 分档：≤10“珍稀”、≤30“少见”、其余“常见”；特殊取得显示“特别”，地区品种显示“地方”。它是图鉴展示分档，不是新玩法，也不表示某一锅的实际出现概率，提示中明确说明。

首次收取新品种显示画像和入册提示；若同时触发手艺奖励，同一提示内保留奖励图标与信息。读取旧档、重复收取、重载页面不制造新的首次发现提示。

## 尚缺的正式美术

- 48个地区角色的正式 full / portrait / silhouette。目前是独立外形的可替换矢量概念稿，未声称已经完成绘本级角色制作。
- 24张发现卡的专属叙事画面；现有分类印章已解决辨识与反馈，但同类仍共享构图。
- 12件纪念物的专属正式造型；当前图形能支持收藏与农场陈列，仍需逐件对照设定定稿。
- 4位常客的正式肖像；姓名标识仍保留，未拿不相符的角色图替代。
- 4个路线小景的最终质感，以及原75食材与旧角色低分辨率资源的逐步统一。

## 后续最值得提高的5个视觉区域

1. **地区角色身份。** 逐个正式绘制48个角色，优先首标本关联品种；统一农场脚底锚点与图鉴头像比例。
2. **发现的叙事瞬间。** 为标本/见闻/事件补专属插画和短揭页动画，让首次发现拥有独立画面记忆。
3. **农场陈列与常客。** 完成12件纪念物和4位常客肖像，让长期收集的成果落到真实物件和人物上。
4. **厨房动作。** 精修破壳、入篮、蒸汽与分阶段脏污，让反馈和当前厨具/食材匹配，并继续控制同时出现的提示。
5. **旧新美术的精度统一。** 优先重绘高频75食材中的常用项、低清角色头像，避免先大规模替换已经有效的场景。
