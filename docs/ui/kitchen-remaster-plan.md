## Lv.2 的唯一实施方案

阅读顺序：顶部 HUD → 自然蛋窝 → 紧邻的孵化状态 → 调味/脏污 → 厨具 → 原 Bottom Navigation。商店/仓库/手艺在旧搁架上共用承托，不侵入蛋窝与窗；帮助降为小型辅助入口。保持现有画面的墙/桌分区与蛋窝尺度，不改成管理卡片。

原型路径：`web/prototypes/kitchen-remaster/`。复用正式 HTML 外壳、真实玩法与 Work 2 页面，只在独立入口中覆写视觉层。使用独立 review 存档；所有正式文件在开始前记录 SHA-256，结束时逐一比对。禁止修改 engine、经济、RNG、存档 Schema、配方、解锁与升级规则。
