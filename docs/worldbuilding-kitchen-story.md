## 2. 世界、厨房与玩家

### 2.1 风味生物

鸡宝与鸭宝是两大类风味生物。蛋在适合的调理条件中形成它们的身体，食材、厨具与环境会留下不同的风味和外形。每项图鉴对应一种可以反复出现的品种，不是一个独一无二的人物。

它们会活动，有简单的感受和习性，可以辨认熟悉的气味与环境。轻微拟人用于表达趣味，不由此推导公民身份、职业、语言社会或复杂的人生。某些身体像食物，某些像动物、节物或传说形象，均可属于同一个世界。

食用、观赏及寻找材料是人们与这些生物相处的不同用途，可以落在同一品种上，不形成社会阵营。无需按售价或稀有度分配用途，也不宣称所有病变、焦化或特殊形态都适合食用。

### 2.2 厨房为什么存在

调理风味生物是当地已有的手艺与生意。厨房负责生产，农场用于暂养、观赏以及等待出售；杂货供应与收购渠道把厨房连接到家庭、餐饮和观赏市场。

出售是实际交易。玩家取得CP后继续购买材料、改善条件和经营，不把交易重新解释为收养补贴或照料费。普通鸡鸭有稳定的日常需求，新品种使厨房逐渐形成特色；持续生产的理由不依赖每次都发现稀有品种。

这里的市场与买家是世界背景，不要求新增顾客选择、浮动市场、餐厅管理或配送系统。蛋可沿既有购买渠道取得；其更上游的生产过程保留留白，不为解释厨房而另写一套繁殖系统。

### 2.3 玩家为什么现在开始

玩家希望凭手艺建立自己的生活，主动接手一间已停业、逐渐失修的普通厨房。厨房曾为附近供应出品，旧设备与旧招牌还在，而新经营者的第一批出品尚未做出来。

这是主动经营的起点。前任的身份、停业原因和转让条件没有确定；“前任退休”“玩家曾做学徒”“低价接手”均不写入正式历史。主线无需债务、失踪或灾难驱动，也不因此添加租金和限时考核。

近期目标是重新营业，中期目标是学会更多做法、找到自己的招牌，第一部终点是确认厨房已经成为自己的事业和生活。之后仍会有外地材料、季节与配方带来新问题，但本地故事有自己的完整结束。

## 3. 特殊内容的共同规则

形态通常在调理成形时受材料和环境影响；少数特殊经历也能使既有个体发生变化，时空旅行即为已确认的一例。影响有具体条件，不意味着想到什么就能造出什么，也不推导所有外出都能改变品种。

| 内容 | 正式解释 | 获取与写作边界 |
| --- | --- | --- |
| 普通／料理 | 材料与调理使基础鸡鸭呈现食物风味及形态 | 实际配方决定结果；不从故事新增必需材料 |
| 四时手作 | 人们把季节味道整理成常备手艺，如夏天也能做冬日点心 | 现有16项全年可发现，条件仍以数据为准 |
| 节日品种 | 某些形态还需要相应节令的出现时机 | 开火日期影响候选，既有个体和已确定批次在节后保留 |
| 神社与御神签 | 神社延续地方习俗，保存并提供能参与调理的特殊媒介；签意显现在签鸡上 | 不创造额外运气或经济效果；当前加权随机和历史轮换都只是供签规则，不写成宇宙法则 |
| 妖怪形态 | 奇异轮廓使人联想到夜话和传说 | 不必安排亡魂、前世或妖怪阵营；木绵、火苗是媒介，产物另有身份 |
| 凤凰 | 与特定光照时段和调理条件相应的华丽品种 | 不添加复活、控火或天气判定；具体时段按数据 |
| 时空鸡 | 普通鸡宝在时空旅行中发生变化，归来成为时空鸡 | 同一个体变化是正式故事解释；目前以一换一实现，不增设历史改写、年代选择或复制 |
| 病变／焦化 | 调理和照料条件可能留下不理想的变化 | 不加治疗、自动恢复、可食用保证；脱逃仍是离开农场，不是探索收益来源 |

“季节风味”与“节日窗口”分开，是扩展时应优先保留的边界。新四时外观不自动受到日历限制，新节庆故事也不能擅自改变既有配方资格。

## 4. 外部人物：两个职能足够

### NPC-01 杂货铺掌柜

承担材料、厨具的供货背景与出品的收购渠道，也见证玩家逐渐站稳。语气务实、熟悉日常生意，鼓励落实在小事上：先有一样能做的、这一批有人买、下一批愿意再看。

掌柜不是万能导师。配方说明须来自实际数据，探索样本可以请其辨认，但不能凭一句话授予尚未设计的材料、资格或奖励。商店、出售和剧情仍可有各自入口，不要求每次买卖都播放对话。

### NPC-02 旧厨房老顾客

记得这里过去的出品，会为了家里的一顿饭等具体需要再次上门。人物的作用是带来有回报的生意，让玩家认识到“做得熟悉”与“做出特色”都有人需要。

采购事件有一次性额外收入，偶尔还可提供下一段线索。当前采用基础货款＋完成时一次性酬谢，数量与门槛见游戏设计；不默认全局永久增益或每日订单。

两者均只使用职能名，姓名、性别、年龄和外貌不必提前决定。台词可由文本呈现；人物头像与立绘继续为低优先级D04。不要为缺少人物图而把厨房剧情推迟到完整城镇建成以后。

## 6. 第一部：三章梗概与关键正文

以下为本轮交付文本。场景可被拆成短对话或章节摘要，具体触发和展示长度由B、C适配。CH-02选择现有、全年可制作的茶叶蛋鸡作为代表出品，避免第一部等待节日；这是一项叙事选材，不新增配方。

### CH-01 重新开火：第一笔生意

**目的与收束：**完成一次普通经营，让玩家看到厨房确实能养活这门生意。只需对接现有调理、收取和出售，故事不另外承诺免费材料或额外奖励。

门外响起敲门声时，第一批鸡宝还没出壳。

杂货铺掌柜看了看擦亮的台面，把空筐放在门边：“这里又开火了？”

你点点头，又回头看了一眼。厨房里能做的东西还不多，旧招牌上的字倒有好几行。

“先有一样就行。”掌柜说，“摊上每天都有人买普通鸡宝。”

蛋壳轻轻动起来。一只鸡宝探出头，旁边又冒出一只。最先出来的挤到一起，后来的绕了半圈，还是决定往那团暖乎乎的空隙里钻。

你把出品安顿好。等掌柜收下这一批，手里便有了重新营业后的第一笔收入。

钱不算多。台面的一角还旧着，没用上的地方也还空着，但下一回开火的打算已经有了着落。

掌柜拎起筐，临走时望了望招牌：“下回做了别的，也让我瞧瞧。”

门合上后，你翻开自己的出品记录，写下“鸡宝”。想了想，又在旁边添了一句：有人买。

**接入提示：**以玩家实际完成的第一批普通鸡宝交易为语义前提，不因读到对白自动出售库存；若引导顺序变化，延后播放即可。出品记录是叙事物件，不要求新增可交互手记。

### CH-02 找到自己的招牌：一份有茶香的采购

**目的与收束：**老顾客提出实际需求，玩家准备茶叶蛋鸡并取得该次额外收入。老味道是来访原因，玩家自己的经营是故事落点。

老顾客是在又一次开火时来的。

站到门边，先闻了闻，才问：“这里还做茶叶蛋鸡吗？”

你看向自己的出品记录。那一页还可以添东西。

“家里想备一份一起吃。”来客说，“以前从这里买过，茶香很足。你若愿意专门准备，我就按这次约好的价钱收。”

这回，试一种做法有了具体的去处。

你查清需要的材料和厨具，准备好下一批。等茶香渐渐漫开，褐色的鸡宝从蛋壳里探出脸，头上的小壳帽晃了晃，又歪向另一边。

老顾客再来时，没有急着比较。

先低头闻了闻，然后笑起来：“就是想让屋里有这么一股茶香。”

你按约定交出准备好的出品，收下这笔比普通收购多一些的收入。来客把东西放稳，又问：“你这儿以后还打算做什么？”

你原先想说，还在学。话到嘴边，却先看了一眼那页新添的记录。

“这份想继续做。”你说，“别的也会慢慢试。”

“那下回我来看看。”

来客离开后，厨房安静下来。你在茶叶蛋鸡旁边留了个小记号。普通鸡宝那一页也没翻过去太远，明天的日常出品还用得上它。

**接入提示：**此章选用现有茶叶蛋鸡，不要求新配方、品质等级或自由调味。正文“那一页还可以添东西”兼容已收录和未收录玩家；后续分别提示准备或发现即可。接单、交易、额外CP只在B02确定并实现后结算，不能仅播放文本就扣库存。采购数量、金额及触发等级留待B02；没有现实倒计时和失败罚款。

### CH-03 厨房有了自己的名字：下一回，也从这里开火

**目的与收束：**让玩家确认普通经营和代表出品一起构成自己的厨房。收束不依赖豪华等级、全收集、现实节日或探索已上线。

掌柜来收出品时，先把空筐靠到了熟悉的位置。

“今天还是这些？”

你把准备好的东西一一摆开。普通鸡宝挤成一小团，带茶香的那一批在旁边慢慢探头。出品记录翻到常用的几页，边角已经不像刚开始时那样平整。

掌柜看过，点点头：“有人问我，旧厨房现在做什么。”

你停了一下，想起最初那张写着“有人买”的记录。

“我说，日常的有，带茶香的也有。要找这一口，就认准你这里。”

门外的老顾客接过话：“那下回可别只说旧厨房了。”

几个人抬头看向门边。招牌还是那块招牌，曾经空着的地方，现在已经有了每天开火、收拾、准备下一批的痕迹。

你把出品记录放回手边，把这次的收入收好。

明天还要开火。常做的继续做，没试过的也还有很多。

只是下次再有人问起这里时，你已经知道怎样介绍它了。

**接入提示：**“有了自己的名字”指经营身份成立，不要求文字输入、命名奖励或新招牌美术。可在相关经营节点之后播放；数字条件由B组确定。以上展示出品不额外消费库存，不新增第二次采购奖励。第一部至此结束。

### 可选后续引子：多出来的香气

掌柜收拾好筐，提起外地新见的一种气味：“闻着像熟悉的叶香，后头又有一点不一样。”

你在出品记录的空白处留下一句：下次找个样本闻闻。

这段只给探索留下问题，不自动解锁路线或凭空赠送材料。若探索尚未接入，可不播放；前三章仍然完整。

## 7. 探索为什么由鸡鸭承担

玩家需要继续照看厨房；鸡鸭善于贴近地面活动，能辨认气味、进入草丛和浅水边寻找小样本，经简单引导带回物件。两者因此分工，探索所得回到厨房转化为材料知识与新做法。

熟悉的农场、喂养气味和走过的路线是归巢依据。这是一条背景习性，不需要逐只训练、亲密度、饥饿或装备系统。远途如何安排，等实际路线范围明确后再补，当前不承诺所有距离都能自行导航。

| 代表品种 | 已采用的习性方向 | 不从故事推导的效果 |
| --- | --- | --- |
| 鸡宝 | 翻找地面草籽与小物，承担周边日常采集 | 固定产量、必出稀有素材 |
| 鸭宝 | 在浅水边活动，寻找岸边样本 | 所有鸭种潜水、横渡、免疫危险 |
| 茶叶蛋鸡 | 对茶香更敏感，可辨别相关气味 | 自动产茶、强于一切普通品种 |

品种共享能力表，具体值见游戏设计，不强制193项各有独占技能。鸡鸭的联系可来自一起寻找和相近风味，不需要个体故事或羁绊效果。

探索线索来自带回的材料、附着叶片与花粉、走过环境留下的痕迹，经经营者和掌柜辨认。鸡鸭不必讲述完整旅途，也不自动带回可解锁一切的食谱。

普通探索使用真实持有数量，外出数量不可出售、不能继续占据在家展示；同品种留家的数量仍可用。归队解除占用，不凭空复制。时空旅行的品种变化为特殊交换，和普通采集归队分别结算。具体时间、收益与存档见游戏设计和工程文档。

## 描述文风

面向已经发现该品种的读者，先说清“它是什么”。含蓄留给线索，描述不再重复出一道谜题。保持轻松、食物趣味和具体观察，复杂品种可解释来源与造型，基础品种说清即可。

| 参考篇幅 | 内容选择 |

| 基础约30—60字 | 基本性质与一个辨识动作 |
| 料理约60—110字 | 风味、身体构成与相关趣味 |
