# 字体构建输入

这里保留生成器实际读取的原始字体，游戏运行时读取 `web/fonts/` 的子集。

| 输入 | 使用方 | 许可 |
|---|---|---|
| `NotoSansSC-wght.ttf` | `tools/build-font.py` | [Noto Sans SC OFL](../../web/fonts/OFL-NotoSansSC.txt) |
| `ZCOOLKuaiLe-Regular.ttf` | `tools/build-golden-display-font.py` | [站酷快乐体 OFL](../../web/fonts/OFL-ZCOOLKuaiLe.txt) |
| `resource-rounded/ResourceHanRoundedCN-{Regular,Medium,Bold,Heavy}.ttf` | `tools/build-journey-font.py` | [资源圆体 OFL](../../web/fonts/OFL-ResourceHanRounded.txt) |

下载压缩包、未采用字体和额外字重留在本机，不随源码上传。不要移动这里的输入而不更新生成器。
