# 产物与本地归档

这里同时包含历史证据、生成输入和本机输出，不能整目录删除或上传。

| 类别 | 保留方式 |
|---|---|
| `original-source/`、`font-source/` | 内容／字体构建输入，固定路径；所需源文件与许可入库 |
| Git 已跟踪的脚本、素材来源和历史证据 | 保留原路径，避免破坏来源链与固定路径工具 |
| `source-backups/`、`device-backups/` | 本机源码快照和真实存档备份，独立保存，不入库 |
| `releases/`、`candidates/` | 本机安装包与版本信息；APK 不入库 |
| `qa/`、各测试输出目录 | 可重新生成的验证产物，新增内容默认忽略 |
| `local-archive/` | 整理后的旧轮次原件，仅本机保留；按其中清单恢复到原路径再复跑历史脚本 |
| `cleanup-20261009/` | 本次整理的本机清单、验证输出和处理记录，不入库 |

新截图、日志、浏览器档案、美术中间稿、下载压缩包不自动进入 Git。只有确需长期复核的最终证据、脚本或生成输入才显式加入；结论写进对应文档，避免保存多份聊天过程。

2026-10-09 整理：67 个未跟踪的旧轮次目录、5,274 个文件压缩为 `local-archive/historical-rounds-20261009.zip`（约 1.30 GiB），全部原件逐一核对 SHA-256 后移除。ZIP 内保留项目相对路径及 `archive-manifest.json`；需要查看文档中的旧截图或复跑旧脚本时，先将所需轮次解压到临时目录，检查后恢复原路径，避免覆盖新结果。归档含私人测试资料，仅本机保存。

另外清理已停用的测试模拟器磁盘和下载镜像，合计约 36.81 GiB 文件逻辑大小（稀疏文件实际磁盘回收量可能不同）。清理前确认无模拟器运行；源码快照、正式签名、真实设备备份均保留。日常构建会在原输出路径重新生成新结果。
