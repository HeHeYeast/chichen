# 已选地图 + 小比例鸡宝预览

用户于本轮明确选定附件中的环河营地为地图。地形、建筑和构图以此图为准，旧 A/B 世界方案仅作历史实验，不再作为当前地图推荐。

原图 1536 × 1024，保存在 `assets/map-user-approved.png`，从用户附件原字节复制；不调色、不重生成地图。独立 DOM 图层叠加 8 只正式鸡宝（现有 id 0 / 3 / 4），原图尺度高 18–20 px。按门洞可见高度约 35–40 px 估读，鸡宝约为门洞的一半高；农舍完整屋顶宽约 145 px，是鸡宝高度的 7–8 倍。这里是对用户已选原图的尺度校准，不沿用旧图强行规定的世界 px 尺度。

中央 4 只，农舍 / 补给 / 神社 / 陈列附近各 1 只。脚点选择在裸露草地或道路，避开现有树冠、建筑、灌木、水面。当前没有行走动画、碰撞与前景遮挡分层；角色保持独立层，后续若走进树后，需要前景遮挡或避让处理，本轮不改地图。

打开 `/web/prototypes/farm-map-resident-preview-20260929/index.html` 可全图查看、放大、拖动，或关闭居民图层对照原图。全图预览默认 fit，仅为查看用户提供的地图与居民效果，不修改上轮正式手机 Camera 默认定义。

输出：`evidence/map-with-residents.png` 是浏览器按原图 1536 × 1024 渲染的地图 + 角色图层；`evidence/detail-native-scale.png` 是同一页面按 1:1 比例查看的局部。没有调用 ImageGen，没有修改旧原型、正式 Runtime 或 Kitchen。
