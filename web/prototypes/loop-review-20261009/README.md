## 第一版与流程说明

独立设计预览，不读写正式存档。两个布局共用一套示例流程：A 为摊前交谈，B 为来访便笺。人物候选由图像生成工具制作，等待用户确认后才进入正式素材库。

在项目根目录运行 `node server.mjs 4191`，打开 `http://127.0.0.1:4191/web/prototypes/loop-review-20261009/index.html`。页面顶部可以跳转环节，按钮能逐步体验、修改摆货数量、查看帮助。

本例中荠菜煎饼鸡收获 7 只、留 1 只在家；香煎鸡有 8 只可摆。两种各摆 6 只满足当前家常小铺完整组合，符合菜单的出品加价 25%。收获数量为示例，不是必出规则。

验证入口：`node tools/qa-loop-review.mjs`，输出位于 `artifacts/qa/loop-review`；还会独立验证真实新伙伴页和商店标签。测试创建临时浏览器上下文，不访问用户浏览器或存档。
