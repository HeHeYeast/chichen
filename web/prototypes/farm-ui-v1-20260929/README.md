# Farm UI V1 · 390 × 844

交付图：`farm-ui-v1-390x844.png`。可编辑视觉源：`index.html`。本目录只包含独立设计稿，未修改 Runtime。

## 设计决定

- **顶部 HUD**：100 px 奶油色整合带。第一行集中头像等级、金币、页面标题和设置；第二行用更小字号显示“在家 0 位”“整修 59%”。数值始终可见，地图从 y=97 开始。
- **建筑入口**：首屏仅显示地图里可见的仓库与陈列亭。地点牌均为 120 × 46 px，图标均为 30 × 30 px；尖角分别指向农舍屋顶与陈列亭篷顶。其余地点随地图拖动出现，标签应绑定世界坐标并在建筑离屏时隐藏。仓库与陈列亭均使用现有 Runtime 地点语义。
- **地图控制**：右下角 42 px 宽双层缩放和独立归位。全景放在非主操作层，不占首屏常驻位置。
- **任务提示**：导航上方 56 px 的卷轴任务条，点击跳转厨房。任务文字浓缩为“迎接第一位鸡宝”，保留原功能意图。任务条与地图控件横向间隔 16 px，与底栏纵向间隔 20 px。
- **底栏**：79 px 五栏；图标大于文字。农场以浅金色圆角底座高亮。各栏宽 78 px，图标和文字在栏内居中。独立可复用方案见 [`bottom-nav-compact-v1`](../bottom-nav-compact-v1/README.md)。
- **地图**：`../../art/farm/camp-map.png` 作为真实底图，原图 1536 × 1024，不重绘、不调色。视觉稿使用 0.7 倍缩放，原图在 390 px 视口内的左上角为 (-192, 93)，首屏可见农舍、陈列亭、中央道路和河流。地图区域约 667 / 844 px，接近 79%。

## Runtime 新 UI Asset 清单

1. **HUD**：鸡宝头像框与等级牌、金币徽章、设置齿轮、在家小鸡与整修芽叶图标、HUD 九宫格面板。
2. **地点牌**：通用奶油色气泡九宫格与尖角、仓库图标、陈列亭图标；为后续可见地点准备补给摊和神社图标。
3. **地图操作**：缩放双层底板、加减号、归位准星；全景小图标供次级入口使用。
4. **任务**：任务卷轴图标、任务条九宫格底板、跳转箭头。
5. **主导航**：厨房厨师帽、农场鸡宝、生意店铺、寻访地图、图鉴书本五枚正式图标，以及农场选中底座和底栏九宫格背景。

`index.html` 中的矢量图标是上述 Asset 的形状与比例基准。Runtime 制作时应输出统一描边、阴影和像素密度的正式资源，不使用 Emoji 字形。
